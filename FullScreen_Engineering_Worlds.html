V22 將人物、走道和設備放在同一個連續空間。使用鍵盤或觸控搖桿行走，走近設備後開始工程任務。

本機使用請先啟動網站。
新版使用 JavaScript ES 模組，需要透過 HTTP 開啟；直接雙擊這份 HTML 不會啟動 3D 行走。

macOS／Linux

在解壓後的專案資料夾開啟終端機，執行：

bash run-local.sh

Windows

執行專案資料夾內的 run-local.bat。電腦需有 Python 3.10 以上版本。

依啟動工具顯示的網址進入學院，選擇「全畫面工程世界」。若使用預設連接埠，也可開啟 http://127.0.0.1:8010/experience.html；如工具選了其他連接埠，請以工具顯示的數字為準。
