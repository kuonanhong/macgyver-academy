# MacGyver Engineering Academy V16

鐵道與交通 100 門專題、彩色課程圖示、按需載入的實景教學場景，以及伺服器管理員權限。

開始使用：[START_HERE_V16_ZH.md](START_HERE_V16_ZH.md)。

```bash
bash run-local.sh                     # 本機帳號與 AI 後端
bash Upload_MacGyver_v16_SSH.sh        # SSH 上傳新增／修改內容
```

完整離線閱讀可開啟根目錄 `index.html`。公開靜態試讀輸出用 `bash deploy-static.sh`。管理員私人設定另包提供，不能放入公開 GitHub。

Authored Traditional Chinese and English; 79 language targets with configured translation. Licensed representative photography and original 3D teaching models; no calibrated live digital twin. AI providers or local models require configuration; model weights and credentials are not bundled.

See [owner setup](docs/OWNER_ACCESS_V16_ZH.md), [SSH upload](tools/upload-v16/README_ZH.md), [scene scope](docs/IMMERSIVE_V16.md), and [validation](docs/VALIDATION_V16.json).
