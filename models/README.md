# Optional model files

No model weights are bundled or represented as already installed. Place only weights you are authorized to redistribute here. Weights here are never uploaded to the public site repository. To back them up in the private repository `PRIVATE-MODELS`, run `bash macgyver.sh models` (32 MiB SHA-256-verified fragments, resumable); see ../docs/AI_MODELS_V12_ZH.md. Ollama keeps its own downloaded models separately. Uploaded weights still require a compatible model runtime; uploading them does not activate AI. See ../docs/LOCAL_AI_ZH.md.
