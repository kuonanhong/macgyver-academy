# Optional model files

No model weights are bundled or represented as already installed. Place only weights you are authorized to redistribute here. `push-updates.sh` detects large/model files and requires Git LFS or an explicit `--models-remote` rclone destination. Ollama keeps its own downloaded models separately. Uploaded weights still require a compatible model runtime; uploading them does not activate AI. See ../docs/LOCAL_AI_ZH.md.
