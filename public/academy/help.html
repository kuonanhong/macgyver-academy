AI 四條執行路線

模型選項依記憶體、速度及問題類型取捨，沒有一個模型對所有裝置與工程題目都最好。服務尚未設定時會提供操作說明，不會把教材摘要冒充生成式回答。

① 瀏覽器 CPU · 文字

Qwen2.5 0.5B 約 491 MB；Qwen3 0.6B 約 639 MB。先勾選下載同意，再載入。可取消、卸載或清除快取。

需要 HTTPS 或本機 HTTP。雙擊 file:// 可學課程，但不能可靠執行模型 worker。手機記憶體不足時請選伺服器路線。

② 本機 Ollama · 文字

Qwen3 4B，約 2.5 GB。較大模型通常需要更多記憶體與等待時間；由電腦 CPU 執行。另保留 llama.cpp 的 Qwen3 1.7B 方案。

bash run-ai-local.sh --download

腳本在解壓目錄執行。已下載後移除 --download；需先安裝及啟動 Ollama。

③ 本機 Ollama · 看圖提問

Qwen3-VL 2B，官方標示約 1.9 GB。可提供工件照片、圖表或畫面截圖；選擇圖片只會預覽，按送出才交給本機模型。

bash run-ai-local.sh --both --download

同時提供文字與視覺路線；支援 PNG、JPEG、WebP，單張最多 4 MiB。小字與複雜尺寸仍須自行核對。

④ Gemini · 雲端文字與圖片

預設 Gemini 3.5 Flash-Lite，站長可在後端指定其他可用型號。金鑰放在後端環境或私人 .env，每次送出需勾選同意將問題、課程脈絡、近期對話及選擇的圖片交給服務。

bash run-ai-gemini.sh

先設定 GEMINI_API_KEY；費用與額度依 Google 專案而定。金鑰不可寫入 HTML、config.js 或 GitHub。

本機服務需 Python 3.10+；pip install python 不能升級直譯器。可用 conda create -n macgyver python=3.12 建立環境，再 conda activate macgyver。一般瀏覽課程不需要 Python。Windows 可用 Git Bash／WSL，Ollama 另附 PowerShell 啟動檔。

內容與測試範圍

全站 2,066 個編輯選題，其中 515 門逐步課程、13,042 步，另有 1,551 項研究工作表。本次資訊／資安 100 門共 3,254 步，另加 80 門量子、神經網路與加速器、伺服器、能源及資源工程。請由「課程地圖」查看門派、分支及先修路線；原有課程與進度 ID 保留。新增 180 組雙語原創架構、雙量子位理想模型及 12 個可下載 Python 小實驗。正式數量見 data/release.json。

這是公開原理、計算與工程判讀教學，並非各廠完整量產配方、施工許可或獨立精密物理模擬。照片明示代表用途與授權；不是每道工序專屬實拍。學習圖的文字有中英兩版，其他語言頁面文字依設定的機器翻譯處理。

資料契約、互動邏輯及金流模擬測試不等於全裝置驗收；未刷真實信用卡，未以你的 Gemini／Supabase／海外行情私人憑證實測，也未逐款手機、電腦測試語音、大型模型或第三方內嵌。

Quick start

  1. Extract the entire new archive. Open its outer index.html; update old bookmarks. The sidebar reads 11.
  2. Open Learning Map for branches and prerequisite routes. Computing & Security contains 100 courses and 3,254 steps; 80 additional named world projects cover quantum, neural networks, accelerators, servers, energy and resources. V11 has 515 guided courses and 13,042 steps. All earlier semiconductor, packaging/photonics and electrical/electronics courses remain available.
  3. Open AI Mentor at the top right. Browser CPU models accept text only and require HTTPS or local HTTP. Ollama text/vision and Gemini are optional configured server routes. Images stay in preview until you submit; cloud requests require consent each time.
  4. The account button creates a device-local name/email profile. True email authentication and cross-device progress on GitHub Pages require your Supabase configuration; see the included SQL and account guide.
  5. Filter Sources by discipline, technical subdiscipline and citing course. Photos include attribution and license links.
  6. My Workspace saves theme, layout and speech preferences per local profile. Browser/page language is used by default, not GPS. Membership pricing is a launch hypothesis; live checkout is disabled. A separately configured protected HTTPS server is required for paid access and verifiable platform completion certificates.
  7. Company links show course-to-industry connections. TWSE quotes are end-of-day data; foreign quotes require a licensed server-side feed. Both Holo-Artisan showcases load only after you choose to embed them.
  8. Use the supplied Bash scripts to export and push source. Weights download separately with consent, and may be copied to an explicit rclone destination. Never put private API keys in public files.

Traditional Chinese and English are the authored core. Other language choices require configured machine translation. The exercises explain engineering principles; they are not qualified manufacturing instructions or a full physical simulator.
