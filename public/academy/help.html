AI 四條執行路線

模型選項依記憶體、速度及問題類型取捨，沒有一個模型對所有裝置與工程題目都最好。服務尚未設定時會提供操作說明，不會把教材摘要冒充生成式回答。

① 瀏覽器 CPU · 文字

Qwen2.5 0.5B 約 491 MB；Qwen3 0.6B 約 639 MB。先勾選下載同意，再載入。可取消、卸載或清除快取。

需要 HTTPS 或本機 HTTP。雙擊 file:// 可學課程，但不能可靠執行模型 worker。手機記憶體不足時請選伺服器路線。

② 本機 Ollama · 文字

Qwen3 4B，約 2.5 GB。較大模型通常需要更多記憶體與等待時間；由電腦 CPU 執行。另保留 llama.cpp 的 Qwen3 1.7B 方案。

bash run-ai-local.sh --download

腳本在解壓目錄執行。已下載後移除 --download；需先安裝及啟動 Ollama。

③ 本機 Ollama · 看圖提問

Qwen3-VL 2B，官方標示約 1.9 GB。可提供工件照片、圖表或畫面截圖；選擇圖片只會預覽，按送出才交給本機模型。

bash run-ai-local.sh --both --download

同時提供文字與視覺路線；支援 PNG、JPEG、WebP，單張最多 4 MiB。小字與複雜尺寸仍須自行核對。

④ Gemini · 雲端文字與圖片

預設 Gemini 3.5 Flash-Lite，站長可在後端指定其他可用型號。金鑰放在後端環境或私人 .env，每次送出需勾選同意將問題、課程脈絡、近期對話及選擇的圖片交給服務。

bash run-ai-gemini.sh

先設定 GEMINI_API_KEY；費用與額度依 Google 專案而定。金鑰不可寫入 HTML、config.js 或 GitHub。

本機服務需 Python 3.10+；pip install python 不能升級直譯器。可用 conda create -n macgyver python=3.12 建立環境，再 conda activate macgyver。一般瀏覽課程不需要 Python。Windows 可用 Git Bash／WSL，Ollama 另附 PowerShell 啟動檔。

會員帳號：帳號、密碼、信箱、手機

本機會員（離線也能用）

右上帳號 → 建立本機會員，填寫帳號、密碼（至少 12 字元）、信箱、手機號碼四項。資料只存在此瀏覽器，密碼以加鹽雜湊保存；切換到有密碼的帳號需輸入密碼。這不是跨裝置帳號，換電腦前請先匯出 JSON。

雲端會員（GitHub Pages）

站長設定 Supabase 後，學員可用四項資料註冊、點信箱連結驗證，之後以帳號或信箱登入、跨裝置同步進度與個人設定。帳號與手機不可重複註冊。

設定見壓縮包 docs/PAYMENTS_V12_ZH.md 與 supabase/002_accounts_commerce.sql。本包沒有內建任何帳號秘密。

我的工作室：外觀、版面與語音

頂部「我的工作室」可切換淺色／深色／系統、強調色、字級、舒適／緊湊佈局、側欄（完整／精簡／隱藏）；原有課程與功能皆保留。設定按會員分開保存，雲端會員登入後跨裝置套用。

更新網頁、比對雲端、每週股價與模型

於解壓資料夾終端機執行（Mac／Linux；Windows 用 Git Bash 或 WSL）。第一次先依 docs/UPLOAD_SYNC_V12_ZH.md 設定 SSH 金鑰。

bash macgyver.sh doctor     # 檢查環境與 GitHub 認證
bash macgyver.sh compare    # 比對本機新套件與 GitHub：新增／修改／刪除／相同
bash macgyver.sh            # 一鍵：只上傳新增與修改，刪除雲端多餘檔案
bash macgyver.sh stocks     # 每週股價與匯率；schedule 可設定每週一自動執行
bash macgyver.sh models     # AI 權重（可由華佗 ZIP 匯入）只上傳私人倉庫沒有的分片
bash macgyver.sh models-compare   # 先看私人倉庫已有／需上傳的分片
bash upload-all.sh          # 一鍵：網站＋模型都只傳差異

比對以 Git 檔案指紋逐檔核對，相同檔案不會重傳。模型權重、帳號資料庫、金鑰與 owner-private/ 永遠不進公開倉庫。倉庫內的 GitHub Action 也會每週一自動更新股價匯率。

Quick start

  1. Extract the entire new archive and open its outer index.html; update old bookmarks. The sidebar reads 12.
  2. V13 has 710 guided courses and 20,274 steps, including 100 Bridges & Buildings courses (40 steps each in 5 stages: load path, calculation, verification and failure diagnosis, plus key figures, timelines, codes and landmark comparisons) and the 101 Optics & Precision Instruments courses of V12. All earlier courses and progress IDs remain.
  3. The first section of every guided course is free. A learning pass (NT$299 for 30 days or NT$2,490 for 365 days, shown in your local currency) unlocks the rest. Payment runs on PayPal or ECPay pages; this site never sees card numbers, and access is granted only after the server verifies the payment. Checkout stays closed until the site owner configures Supabase and the payment providers.
  4. Member registration asks for username, password (12+ characters), email and mobile number; sign in with username or email. Local member accounts stay in this browser; cloud accounts sync across devices.
  5. My Workspace saves theme, accent, font size, layout and voice (gender preference, pitch, rate, style) per member. The mentor voice follows your browser language by default, not GPS; available voices depend on your device.
  6. Each course lists related companies with official business and investor links. Listed companies show a weekly delayed price snapshot; “Load live chart” opens a TradingView chart on request. Not investment advice.
  7. Owner tools: bash macgyver.sh compare compares this package with GitHub, bash macgyver.sh uploads only the differences, bash macgyver.sh stocks refreshes prices weekly, and bash macgyver.sh models uploads model weights to a private repository. Never put private API keys in public files.

Traditional Chinese and English are the authored core. The interface also ships pre-translated dictionaries for 77 languages; course text in other languages uses Chrome’s on-device translation where available. The exercises explain engineering principles; they are not qualified manufacturing instructions or a full physical simulator.
