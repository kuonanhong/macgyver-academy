字幕、標題、解說與模型標註完整提供繁中、簡中、英文、日文與韓文。網址的 lang 優先，其次是手動選擇與瀏覽器偏好語言；沒有讀取精確地理位置。語言文字為完整初稿，尚未經所有語系母語工程師審稿。

  • 按「開始導覽」播放，拖曳時間軸或點章節跳轉。空白鍵播放／暫停，左右鍵前後十秒。
  • 雙語模式同時顯示所選語言與英文；選英文時只顯示英文，避免重複。
  • 全螢幕優先使用瀏覽器功能，不支援時改為整頁顯示。手機有橫向技術選單。
  • 「影片與字幕」可下載 MP4 與 WebVTT，或切換為預製影片，供 WebGL 不可用的裝置觀看。
  • 「朗讀」預設開啟，播放已製作的五語合成旁白；以實測語句時間配對字幕。網站在按下播放後才發聲，可暫停、跳章、改速與切換語言。非真人錄音。

預製六部 MP4 的畫面標題與模型標註固定英文，字幕可選五語。即時三維導覽與「製作此語言 MP4」則會使用所選語言的標題與模型標註。

預製 MP4 為 1280×720、24 fps、每部 7,200 幀，含五條 AAC 語音軌（預設繁中）、五條可選雙語字幕與十個章節。播放器是否讀取內嵌字幕依軟體而異；網站使用隨附字幕顯示，多數離線播放器亦可手動載入同名 VTT。影片中的光流、熱區是示意，並非測量值。

YouTube 可提供翻譯標題與說明，以及額外配音；語音預設依觀看者偏好判定，不能保證僅按所在國家強制切換。多語音軌需在 Studio 為有進階功能的頻道發布；多音軌 MP4 上傳本身不保證全部轉成 YouTube 配音選項。已提供「當地語言＋英文」單一雙語字幕檔與五語說明草稿。官方依據：多語配音、翻譯標題與說明。

120 項工序與工程活動

開啟路線圖：共同準備後選擇中介層、扇出、混合鍵合或矽橋／Chiplet 分支，再進入組裝與驗證。120 張中英卡片包含前置、輸入、操作、產出、驗證與失效分析；不是同一條產線必須串行的120站，也不代表120部影片已全部製作。實際影片數以路線圖製作進度為準。

首部逐工序影片：C01 定義系統任務與封裝需求，五分鐘、五語配音與雙語字幕。以頻寬、熱預算、空間、測試存取及可追溯需求作為十段內容；仍有119部工序導覽待製作。C01 原始腳本檔的狀態是製作時凍結快照，實際完成狀態以影片 manifest 與路線圖為準。

本地啟動

一般三維觀看可直接開 HTML；MP4 製作與部分瀏覽器媒體功能請使用本機 HTTP。macOS、Linux、Windows 的 Python 3 可啟動：

bash Start_Packaging_Tour_v33.sh

或在專案根目錄執行：

python3 tools/preview-packaging-tour-v33.py

然後開啟 本機導覽。Windows 可使用 WSL／Git Bash 執行 .sh，或將 python3 改成 py -3 直接執行。終端機按 Ctrl+C 結束。伺服器只綁定本機，僅接受六個指定名稱的影片製作檔案。

製作自己的語言版本

使用支援 WebCodecs AVC 的 Chrome／Edge，開啟「影片與字幕」，選「製作此語言 MP4」，會把選定字幕燒錄進影片。這項功能不需相機、麥克風、API 金鑰或付費服務。這個瀏覽器匯出功能只製作畫面，沒有配音；完整有聲 MP4 請使用下載版或下列製作工具。編碼可取消；不支援的瀏覽器仍可下載現成影片。

本機製作頁另有「製作六部 MP4」，以確定性時間逐幀渲染 30 分鐘影片，原始檔存於專案旁的 MacGyver_Packaging_Tour_Experiment/recordings。完成後可用 Node.js 與 FFmpeg 加入五語字幕、章節並驗證片長：

node tools/export-packaging-subtitles-v33.mjs
python3 tools/finalize-packaging-videos-v33.py --compact
# 網頁重新製作已含 QR；舊版影片才需執行 tools/add-line-qr-packaging-v33.py
node tools/test-packaging-tour-v33.mjs

再次打包可執行 python3 tools/package-packaging-tour-v33.py；工具會核對六部影片的片長、雜湊與字幕清單，產生 ZIP、逐檔清單與 SHA-256 校驗檔。預設輸出在專案旁的 MacGyver_Packaging_Tour_Experiment。修改影片、課文或三維模型後，須重新測試與檢查實際畫面，再更新 docs/VALIDATION_PACKAGING_TOUR_V33.json 的驗證紀錄、影片清單與來源雜湊；舊版 PASS 紀錄不能直接套用。

C01 的畫面製作工作室為 packaging-process-studio-v34.html；執行 python3 tools/preview-packaging-process-v34.py 後開啟工具輸出的本機網址。正式觀看頁與製作頁分開，工作室先產生無聲母片，再加入驗證過的語音與字幕。

五語配音重製

預製影片可跨作業系統觀看。本機配音重製工具使用 macOS 已安裝的 say 語音、Node.js（Intl.Segmenter）、FFmpeg 與 ffprobe；其他作業系統可使用交付的音訊，或提供同格式已授權旁白後合成。此工具不下載模型、不購買語音服務。

python3 tools/build-all-packaging-narration-v34.py --publish-assets
python3 tools/build-speech-aligned-subtitles-v34.py
python3 tools/mux-narrated-packaging-v34.py
python3 tools/prepare-narrated-youtube-job-v34.py

獨立解碼片尾 QR 需要 NumPy、OpenCV 與 Pillow，套件清單在 requirements-packaging-media-v34.txt，實際驗證環境記錄在 docs/PACKAGING_MEDIA_ENVIRONMENT_V34.json。請用已具備這些套件的 Python 執行影音驗證；純標準函式庫的 YouTube 上傳工具不需要影像套件。觀看交付影片也不需安裝。

每句以合成音訊的 samples 量測，章節固定30秒；不同語言的英文第二行以語意對照表對齊，不能按另一語言的播放時鐘直接拼接。

程式與發布

主要程式在 public/academy/packaging-tour-v33.html/.css/.js；內容在 packaging-tour-content-v33.js，三維幾何在 packaging-tour-scene-v33.js。三維與多語資料均隨附，不依賴遠端程式 CDN。線上 MP4 存於本專案 GitHub Release，避免大型影片超出 Pages 容量；獨立 ZIP 仍附全部本機影片及音訊。Three.js 與未修改的 Mediabunny 1.66.2 授權隨 vendor 資料夾提供。

完整學院原始碼保留既有 Update_MacGyver_v32.sh 發布流程。新的一鍵公開網站腳本為 bash Publish_Packaging_Website_v34.sh：驗證六部有聲影片、上傳並核對 GitHub Release 雜湊、同步公開程式、部署 Pages。需要既有 GitHub CLI 與 SSH 授權；--check-only 只驗證不發布。YouTube 另用 Upload_Narrated_V34.sh，帳號上限未解除時應停止。新導覽由原有公開匯出器收錄；不需將私人課程、金鑰、模型或帳戶資料放進 GitHub Pages。獨立導覽 ZIP 是方便觀看與再製的實驗包，不包含整所學院所有原始課程。

重建與真實資料的界線

本片是依 TSMC、Intel、ASE、UCIe 公開資料製作的三維教學重建。具有材質、反射、柔影與動態俯瞰鏡頭，但不是工廠實拍、企業提供的 CAD 或經驗證的製程規範。尺寸、層數與設備配置經簡化；分層與半透明呈現不等同真正的幾何剖切。不能從圖中推算實際尺寸、溫度、良率或壽命。
