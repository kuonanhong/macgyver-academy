Findings communicated to authors and integrator
1. A / a224 worked example: RMS current was incorrectly called a peak RMS limit.
   Corrected to short-time RMS current limit; instantaneous peak is a different
   quantity. Author confirmed rebuild.
2. A / a205 gas-density unit: p/T needed absolute pressure and kelvin, with fixed
   gas composition and ideal-gas approximation. Author confirmed rebuild.
3. A / a231 PV illumination units: the intended input is irradiance (W/m²), not
   photometric illuminance (lux). Author confirmed rebuild.
4. C / a272 Friis worked example: exact NF is about 1.54359 dB; rounded result
   corrected from 1.55 to 1.54 dB. Author confirmed.
5. C / a271 reference/return unit: an unqualified reference-noise statement missed
   the cancellation of correlated excitation/reference changes in ideal
   ratiometric conversion. Corrected to explain residual uncorrelated noise,
   bandwidth mismatch and shared-return voltage drops. Author confirmed.
6. B / a252 field weakening: ASCII absolute-value bars in |Id| broke the six-field
   unit delimiter. Author replaced with abs(Id); independent audit passes.
7. C / a278 reflection/efficiency: ASCII |Γ| broke the eight-field unit delimiter.
   C formula fields a277, a278 and a280 had the same problem, silently splitting
   bilingual formulas into 6 or 10 fields rather than 2. Current input corrected;
   formula count is included in independent delimiter audit.
8. B / a245 rundown loss: positive dissipated power requires −Jω·dω/dt during
   decay, or an explicitly signed stored-energy derivative. Author corrected.
9. B / a237 unity-power-factor dq check: q≈0 requires the d axis aligned to the
   voltage reference. Author now states this convention explicitly.
10. C / a299 station-fire example: linked general/route/history pages did not
    directly document that event. Supplied the official National Grid January
    2023 restoration article, which documents the September2021 fire and return
    to full service, for addition to the source map.
11. C / a295 displacement hysteresis/creep: supplied PI's official displacement
    behavior and forces/stiffness tutorials to supplement TI ultrasound-driver
    references, which did not directly cover nanopositioning behavior.
12. B / NREL wind-report links: historical PDF routes returned502 during two
    independent retrieval methods. Provided working official research-hub landing
    pages for reports75698,38060 and41135, preserving report identity and links to
    full documents. This is an observed access issue, not proof of permanent loss.
