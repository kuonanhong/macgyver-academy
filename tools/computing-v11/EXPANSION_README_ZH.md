# V11 世界級計算與民用能源工程教材

正式整合輸入是 `expansion.json`。以 Python 3.10+ 執行：

```bash
python3 tools/computing-v11/build_expansion.py
```

教材來源是 `expansion_inputs.json` 內保存的原創作者資料與 V10 目錄快照。`author_expansion_inputs.py` 和 `expansion_units.py` 供日後編輯教材；再執行作者腳本會沿用原快照，不把已整合的課程當成新基底。重建不需下載網路資料、權重或第三方圖片。

本包包含 80 項工程、960 個步驟、2,240 筆知識紀錄、103 筆官方／原始研究來源、80 個代表地理參照和160 組衍生比較。14 項原有研究選題轉成逐步課程；66 項使用穩定 `v11-*` ID。原有逐步課程與 a301–a400 資訊教材由主整合程序保存，不由本包覆寫。

每項課程包含六個原理／功能架構單元，每單元兩步：先分析，再驗證。149 個独立編寫的機制單元會在共享物理的工程案例中重用，但案例的系統邊界、元件、算例與比較對象不同。這不是960種獨立高保真設備模型，也不代表實際工廠SOP。

原創算例都明示假設與排除條件。課程會比較 QPU 實體編碼、神經網路計算圖、加速器與記憶體、伺服器互連、民用熱循環以及物料守恆。熱核範圍限和平研究及發電系統，沒有燃料製造、武器、反應爐操作整定或靶設計。油氣與礦業限離線模型，不提供井控、爆破或危險浸出程序。

`architectureNodes` 和 `architectureEdges` 是原創功能示意；圖形不是CAD、晶片floorplan或可施工圖。神經網路的前向路徑、GPU記憶體與互連支路、沸水給水回路、抽蓄雙向水流，以及產品／尾礦支流分開表達。FORGE標為研究與後續假想熱循環，NIF以每脈衝能量分析。

量子地圖八門派都有教材：超導2、QEC1、離子2、中性原子2、光子2、自旋1、退火1、拓撲研究1。Willow的閾值以下表面碼記憶結果不等於完整容錯通用電腦；Majorana原始論文與公司宣稱分開評估；Aurora的擠壓光／PNR資源與homodyne量測，不套用PsiQuantum的單光子來源；Forte不套用H2的跑道QCCD。

地圖座標是公開城市、研究機構或工程區域的近似參照，不是設備定位、施工入口或參訪許可。Nome Creek標示Fairbanks東北方，不是Nome市海灘。Taiwania 2明示2026年8月31日下架，課程研究其歷史架構。
