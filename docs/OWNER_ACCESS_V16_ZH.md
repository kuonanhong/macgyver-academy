# V16 管理員與課程存取

管理員帳號為 `kuonanhong`。管理員角色由本機管理工具寫入伺服器資料庫，登入後可看全部免費與會員課程，不需要購買通行證。單純在瀏覽器註冊相同名稱、修改 localStorage 或送出 `owner: true` 不會取得管理員權限。

## 第一次設定

在完整解壓縮後的 V16 根目錄執行：

```bash
bash setup-owner-v16.sh
```

依提示輸入兩次您指定的管理員密碼。輸入不會顯示在螢幕上；程式只儲存獨立隨機鹽與 PBKDF2-SHA256 雜湊（600,000 輪），不儲存明文密碼。管理員設定接受既有的 8–256 字元密碼；一般會員的新密碼仍需至少 12 字元。

如果另外取得本次交付的私有管理員設定檔，可用它匯入既定密碼，省去重新輸入：

```bash
bash setup-owner-v16.sh --bootstrap "/完整路徑/owner-bootstrap-v16.json"
```

該 JSON 仍屬私密驗證資料，請保留在 `owner-private/` 或專案外，勿放進 `public/`、GitHub 公開庫或寄給學員。公開原始碼包不應包含它。

開啟本機／自架學習伺服器後，在網站帳號表單輸入 `kuonanhong` 與您的密碼。`/api/me` 回傳的 `owner: true` 與 `/api/billing/me` 的管理員權限均由伺服器確認。管理員頁面會標明「全課程永久使用，無需付款」。AI 助教仍需要設定可用的本地模型或雲端 API。

## 已有同名帳號或重設密碼

工具不會默默覆寫已有帳號。確認需要重設該帳號時執行：

```bash
bash setup-owner-v16.sh --reset-existing
```

重設會授予管理員角色並撤銷該帳號既有的所有登入憑證；請重新登入。`--database /路徑/帳號.sqlite3` 可明確指定與學習伺服器相同的資料庫。

## 公開試讀與完整教材的界線

- 公開網站預覽包只含每門課的免費階段與其餘階段的標題／步驟索引，不含會員課文。
- 自架伺服器使用完整 V16 來源與 `COMMERCE_MODE=protected`。一般訪客和未取得通行證的會員，僅能經 API 取得免費階段；有效會員及管理員可取得全課內容。
- 完整課程與補充指南放在 `data/lazy/owner-courses/`、`owner-resources/`，由私有 `owner-index.json` 提供 SHA-256 與檔案長度。受保護伺服器封鎖這些原始靜態網址，連管理員也需經過已驗證的 API。
- 課程首頁先載入索引；選擇一門課時才讀取及校驗該課檔案。伺服器最多暫存 24 門完整課程，無須在啟動時解析整套教材。
- 登出／帳號切換時，前端清除受保護課文與資源；伺服器每次重新判定權限。私有 API 回應使用 `Cache-Control: private, no-store`。
- `file://` 完整擁有者來源包可供離線閱讀，持有者本來就擁有全部教材；它不是可保密的會員部署包。公開完整來源到 GitHub 也會讓人下載全部教材。
- GitHub Pages 只提供靜態檔案，不能執行此 Python 帳號伺服器或建立管理員權限。要在正式網域使用帳號，需部署相同來源的 HTTPS 後端；原有 Supabase 模式需另外設定雲端身分及伺服器權限，這個本機設定工具不會替您建立 Supabase 帳號。

## 維護與驗證

`portable/data/macgyver.sqlite3` 含帳號、進度與管理員稽核紀錄，須與公開靜態目錄分開並備份。密碼重設、角色授予只有本機管理介面，沒有公開的提權 API。

本版以獨立測試憑證驗證：管理員免付款、一般會員權限、偽造角色失敗、公開註冊不能搶註保留名稱、直接下載私有檔案失敗、登出與重設撤銷登入、教材雜湊驗證、補充指南依身分隔離、前端帳號切換競態，以及正式／測試付款權限隔離。測試不使用您的明文密碼，也不進行真實付款。
