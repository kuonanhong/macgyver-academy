# V7 更新與使用方式

完整解壓後，雙擊最外層 `index.html`。不要只複製一個 HTML。網站更新與 ZIP 為同一份課程與前端程式；影片與 Google Maps 需要網路。

## 網站是不是公開的？

此次檢查 `macgyver-engineering-academy.kuonanhong.chatgpt.site` 的主站存取設定，只有擁有者帳號獲准，屬於私人網站；知道網址不代表其他人可進入。本次保留這項設定。

這個網址由 ChatGPT Sites 託管，建立、編輯與主站登入流程與 ChatGPT 有關。網站內容本身是可攜的 HTML/CSS/JavaScript，加上可選後端；不是每次開頁都必須呼叫生成式 AI。未接 AI 服務時師傅以已編寫教材回答。

獨立的 `macgyver-public-player.kuonanhong.chatgpt.site` 只承載核准影片的播放器，是公開的，不含學徒帳號、筆記與進度。影片發布者仍可能限制年齡、地區或嵌入，網站不能取消這些限制。

GitHub Pages 是另一項靜態網站託管服務，一般專案網址為 `https://帳號.github.io/倉庫名稱/`。公開 Pages 可直接供學徒瀏覽，但不會執行本專案的 Python、D1 資料庫或伺服器 AI；只有網頁與本裝置紀錄。跨裝置帳號和 AI 要另外部署後端。

- 20 類有不同原創圖示；2,000 題各有 ID 識別章與原創目錄插畫。它們是視覺識別，不是精密構造圖或實景照片。已有授權實景照片的項目保留照片、作者和授權標籤。
- 「知識與來源」只保留官方資料與照片授權。已刪除「您提供的課程教材」頁籤、表格及發佈資料中的教材檔名／頁數索引。本機自行匯入 AI 的教材功能仍保留。
- 專案簡介列出完整階段／工序與目標，不再只預覽每階段的幾個步驟。
- V6 原有 37 門課與步驟 ID 保留；新增 12 門，每門 4 階段／24 步，共增加 288 步。全部 49 門合計 1,850 步，半導體與封裝仍各 520 步。
- 每門課都有兩項具體相近工程：共通原理、不能直接照搬的差異、比較練習及來源。共 98 組；主工程與相關工程各有代表地點、地址說明及座標。

## 地圖與內容深度

固定結構顯示近似代表點；跨區域設施、供應鏈或通用技術使用明示的代表園區／研究基地。韋伯地圖是地球上的 NASA 據點，不把地圖座標當作太空望遠鏡在 L2 的位置。地圖點擊才連線 Google。

2,000 項中 49 項有已編寫的逐步課程，其餘 1,951 項仍是八關研究工作表；尚未查證的項目不編造專屬地理座標或照片。新增的互動場景是原創概念教具；同主題步驟可共用場景，並非每步一套工業數位分身。
