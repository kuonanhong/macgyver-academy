# V2 工作台操作（舊版對照）

目前 V3 請以 `UPGRADE_V3_ZH.md` 的任務流程與鍵位為準；下文保留作版本對照。

先選課程與目前模組。左邊是你的工件，右邊是師傅目標位置；桌面並列，窄螢幕調整排列。固定操作列顯示組合與驗收兩個狀態。

1. 點「抓取」，用左手方向鍵移動 X/Y；用右手方向鍵調整畫面標示的深度與方向。
2. 鍵盤可用 WASD、方向鍵、Q/E、空白鍵；以畫面的鍵位說明為準。輸入筆記或問題時不會觸發操控。
3. 長按觸控方向鍵可連續移動。精細模式縮小步長；復原回上一次動作，重置回起點。
4. 對照虛線目標，必要時升高工件跨過治具；距離與角度達標後放入。也可用組合輔助吸附目標。
5. 閱讀操作、觀察、異常判讀與知識點，使用互動算例理解變因；再回答驗收題。
6. 完成兩個關卡後按「驗收完成，下一步」。若不能前進，固定操作列會指出缺少對位／放入或答對驗收。

操作姿態保存在目前裝置；正式完成、組合與筆記登入後保存到後端。正在輸入的筆記會在換步、換課或換語言時保存。可在「我的工程進度」匯出 JSON 作備份。

每模組至多 26 步，搜尋至多顯示前 40 個相符項目，避免 520 步擠滿手機。課程路線文字說明不同製程分支。教學解鎖順序不等於實際工廠派工順序。

## 六種互動算例

| 算例 | 控制與觀察 |
|---|---|
| 微影 Rayleigh 關係 | 改變波長、NA、k₁，觀察 CD；含 DUV、EUV、High-NA 情境 |
| 薄膜覆蓋率 | 比較頂面與側壁厚度，計算比例 |
| 互連電阻 | 改變長度、截面與電阻率，計算 R = ρL/(wt) |
| 封裝導熱 | 改變功率、厚度、導熱係數與面積，計算材料層溫差 |
| 理想隨機缺陷良率 | 改變面積與缺陷密度，觀察 Poisson 假設結果 |
| 對準誤差預算 | 比較三個獨立零均值誤差項的平方和 |

每個算例都標明忽略的物理機制。輸入數字是學習情境，不是廠商製程參數或推薦工作條件。
