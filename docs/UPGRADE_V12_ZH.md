## 1. 收費：每門第一節免費，價格依觀看地區換算

- 方案：**30 天 NT$299**、**365 天 NT$2,490**（`public/academy/data/pricing.json`）。
- 免費範圍：每門逐步課程的第一個階段（第一節）；從第二節開始顯示鎖頭與購買說明，進度無法越過鎖定步驟。
- 幣別：依瀏覽器時區（其次語言地區）推定國家 → 當地貨幣，用每週匯率換算並**無條件進位**到該貨幣最小單位；
  學員可在會員頁手動切換幣別。不使用 GPS 或 IP。
- 實際扣款幣別：PayPal 支援的 21 種幣別直接以當地幣別扣款，其餘以 USD；綠界只收 TWD。
  **最終金額一律由伺服器重新計算**，網頁上的換算只是顯示。

## 2. 付款與入帳（嚴格驗證）

- 信用卡／金融卡：由 **PayPal（含「Debit or Credit Card」按鈕）** 或 **綠界信用卡（3-D 驗證）** 的官方頁面輸入，本網站不經手卡號。
- 開通條件：伺服器向 PayPal 請款並逐項核對金額、幣別、訂單編號、收款帳戶；綠界則驗 CheckMacValue 並向綠界查單。任何一項不符就不開通。
- 入帳到郵局：撥款帳戶**只在金流後台設定**，程式裡沒有任何帳號。
  - 綠界：會員後台「提領帳戶」設定本人帳戶（可否直接設郵局請向綠界確認；銀行代號 700）。
  - PayPal 台灣帳戶：只能提領到玉山銀行，再自行轉到郵局。
  - 你的郵局資料與操作步驟寫在 `owner-private/PAYOUT_SETUP_ZH.md`；此資料夾**不會**被上傳到 GitHub（`.gitignore` 與匯出規則都排除）。
- 架設步驟：`docs/PAYMENTS_V12_ZH.md`（Supabase 資料表、7 個 Edge Functions、PayPal／綠界金鑰、Webhook）。
  在設定完成前，網站顯示價格與鎖頭，但**不會收款**，購買按鈕會說明尚未開放。

### 誠實說明：靜態網站的內容保護
GitHub Pages 是公開檔案主機，只靠網頁鎖頭擋不住會下載 JSON 的人。真正保護付費章節要：
上傳付費內容到 Supabase（`tools/paywall-v12/upload_protected_content.py`，RLS 只讓有效通行證讀取）＋
`PROTECT_CONTENT=1` 發布（公開檔只保留每門第一節）。見 `docs/UPLOAD_SYNC_V12_ZH.md` 第 3 節。

## 3. 會員登入：四項必填

註冊需要 **帳號、密碼（至少 12 字元，輸入兩次）、信箱、手機號碼**（台灣 09 開頭自動轉 +886），並同意條款；
登入可用帳號或信箱。三種模式都一致：
- 雲端會員（Supabase）：信箱驗證、帳號與手機不可重複、跨裝置同步、可重設密碼。
- 本機會員（離線 HTML）：密碼以 PBKDF2（21 萬次、加鹽）雜湊，只存在此瀏覽器，切換帳號要輸入密碼。
- 自架伺服器（`portable/server.py`）：帳號／手機唯一、登入失敗訊息不透露帳號是否存在。

### 關於標誌
需求為「馬蓋先與其伙計：霹靂車」。影集人物肖像、劇照與《霹靂遊俠》的 KITT（黑色跑車與紅色掃描燈）都是他人的著作與商標，
不能直接畫進網站標誌。V12 改做**原創**設計：以瑞士刀與扳手組成的「M」徽章，搭配一台有車頭燈眼睛與齒輪天線的鼠尾草綠小車，
表達「工程師與他的智慧夥伴」；不含真人、黑色跑車或紅色掃描燈。原始檔與產生程式：`public/academy/assets/brand/`、`tools/brand-v12/make_logo.py`。

## 7. 多語言與跨裝置

- 介面約 900 個字串已預先翻譯為 **77 種語言**（繁中與英文為原版，共 79 種；清單見 `public/academy/i18n/index.json`），依瀏覽器語言自動選擇，可手動切換；阿拉伯文、希伯來文、波斯文、烏爾都文自動改為由右至左版面。翻譯由 AI 產生並經格式驗證，尚未經各語言母語者審稿。
