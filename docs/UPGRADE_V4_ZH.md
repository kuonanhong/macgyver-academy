# V4 使用與更新說明

## 直接開啟

請完整解壓縮，雙擊最外層 `index.html`。不需要先安裝 Python、不需要啟動終端，也不需要開啟 `127.0.0.1:8010`。入口會帶到同一資料夾內的 `public/academy/index.html`；請保留整個資料夾結構。

離線版使用預先打包的 JavaScript 與課程資料，不以瀏覽器的 ES module／JSON 網路讀取來啟動，因此能以 `file://` 開啟。原始模組、JSON、生成器與建置腳本也全部保留，便於後續修改。

| 功能 | 直接開啟 HTML | 使用後端的網站 |
|---|---|---|
| 課程、照片、工作台、師傅示範、驗收 | 可使用 | 可使用 |
| 不同學員分別保存 | 同一瀏覽器的本機學員檔案 | 登入帳號 |
| 跨裝置進度 | 匯出／匯入 JSON | 同一後端帳號同步完成進度與筆記 |
| 官方影片與 Google 地圖 | 需網路；部分播放器要求從線上網頁載入 | 需網路 |
| 中英課文、雙手控制 | 隨包提供 | 隨網站提供 |
| 其他語言的機器翻譯、生成式 AI | 課程知識回答可用；生成式服務需使用可選後端 | 管理者設定模型服务後可用 |

桌面可使用當代 Chrome、Edge、Firefox、Safari。手機與平板的檔案預覽器可能禁止執行 JavaScript，請使用已部署的 HTTPS 版。響應式觸控版與桌面共用同一份課程與操作邏輯；尚未逐款硬體驗收。

## 工作台操作順序

1. 在「逐步課程」中開啟一項工程。右側師傅播放本步教學動作，包含抓取、移動、調整該步條件、選擇或記錄、放開；師傅狀態與學徒狀態分開。
2. 可以暫停、續播、重播或逐格觀看。示範未完成時，介面會說明目前等待哪個環節。
3. 示範完成後，在左側工作台操作。先抓取工具，再按移動鍵或使用圖面下方的觸控按鈕。按鍵狀態列會顯示收到的按鍵和目前能否操作。
4. 按 Space 抓取／放開；方向鍵或 WASD 控制 XY；I/K 升降，J/L 或 Q/E 旋轉；Shift 精細調整。按 Esc 暫停键盤控制，點回工作台後繼續。在筆記、搜尋、表單或對話框中輸入時，鍵盤不會移動元件。
5. 「操作輔助」協助移動工具到目標。仍須由學徒依師傅提示完成本步的數值、選擇、觀察或執行任務，放開工具，再提交證據。使用輔助會留有紀錄，不把看示範當作已完成。
6. 通過下方知識驗收後，才能進入下一步。已完成步驟保留完成紀錄，可重播師傅示範複習。

控制區緊接在工作台圖面下方，課文、照片、影片與延伸閱讀在其後。每個步驟仍按其任務類型要求不同證據：組裝需對位，辨識需觀察與判讀，量測需正確讀值，製程需執行並核對條件。

這些動畫是教學模型，不是實際機台作業錄影，也不是材料物理、碰撞分析或原廠數位分身。非組裝模式中的可移動元件是示意量測／觀察工具，不能將其位置視為真實製程參數。

## 相關技能與延伸閱讀

17 門逐步課程新增 115 組人工整理的相關技能比較（345 個練習項目，90 個不同的一手來源 URL），提供「為何相關、可遷移原理、重要差異、三步比較練習、公開來源」。例如淡江大橋課程可連到預力混凝土懸臂施工與金門大橋懸索系統，分別比較受力路徑與施工階段。

其餘目錄題目會顯示同領域的自動推薦，並明確標示尚未具備專屬比較教案。相關題目若只有研究路線圖，不會被標示成已有完整逐步課程。新增參考資料是閱讀入口與原創課文的支持來源；不擷取或重製授權不明的完整教材。

示範流程參考使用者提供的 `SmartAction_Taichi_Game_v4_1.zip` 與 [太極教學網站](https://kuonanhong.github.io/taichi/) 的先示範、再跟做概念。V4 師傅時間線為本專案另行編寫；未直接搬用其人物、圖片或聲音。

## 保留舊進度

先在 V3 的「我的工程進度」匯出 JSON，再到 V4 的相應學員檔案匯入。不同瀏覽器、本機檔案位置及線上網址可能各有獨立儲存空間，不能假定自動共享。V4 接受既有完成標記，不會把原本完成的工序突然全部重新鎖住。

若瀏覽器不允許本機儲存，畫面會提示只能保留目前開啟期間的進度。關閉前請匯出；本機學員名稱不是密碼保護，也不是伺服器帳號。帳號後端原有資料庫仍在 `portable/data/`，更新程式時不要覆寫或提交這個資料夾。

## 修改、重建與上傳

課程來源位於 `public/academy/data/`；相關技能的編輯來源是 `tools/related/`。修改相關技能後先執行：

```bash
python3 tools/refresh-related.py
bash build-offline.sh
```

修改兩門 520 步課程的編輯表後，可以執行 `bash rebuild-curriculum.sh` 重建課程、媒体、相關閱讀及離線封裝。只是使用下載包，不需要執行任何建置。

請先建立自己的目的倉庫，完成 Git Credential Manager 或 `gh auth login` 登入。以下是執行範例，需將倉庫與遠端名称改為您自己的設定：

```bash
bash update-and-upload.sh \
  --repo https://github.com/YOUR_ACCOUNT/YOUR_REPOSITORY.git \
  --index-documents \
  --documents /完整路徑/教材資料夾 \
  --documents-remote myremote:macgyver-documents \
  --models-remote myremote:macgyver-models
```

`rclone config` 設定好的目的位置才能用於 `--documents-remote` 和 `--models-remote`；只上傳程式時省略這兩項。模型放在 `models/`，私人教材放在 `local-documents/` 或專案外的資料夾。腳本採增量複製，不刪除遠端額外檔案；Git 歷史分歧會停止，不強制覆寫。Windows 可從 Git Bash 或 WSL 執行 `.sh`。

程式包不含模型權重、帳號資料庫、API 金鑰或私人教材。`run-ai-local.sh`／`.ps1` 可另外下載並啟動支援的 Ollama 模型。上傳權重與啟動模型服務是兩件事；GitHub Pages 不能執行 Python 後端或大型語言模型推論。

## 語言

網站依瀏覽器語言偏好選擇語系，使用者也可自行切換，不以 GPS 或國籍推斷使用者語言。完整中英核心內容可離線使用；79 個語言選項中的其他語言需要已配置的 AI 翻譯服務。技術翻譯尚未逐語言人工審校，並非 79 種完整離線課本。地圖與定位在使用者主動操作後載入。
