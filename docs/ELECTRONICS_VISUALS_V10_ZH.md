# 電機與電子 V10：原創功能圖與互動算例

100 個電機與電子題目（a201–a300）各有一張原創功能關聯圖與專屬 icon。圖以 103 個原創元件／現象符號組合而成；移除文字之後仍有 100 組不同幾何。圖示依主題呈現如汽輪機—發電機—升壓介面、變壓器繞組—磁芯、海纜—海床—海陸接頭、差動電流量測、PLL 參考與回授、PCB 結構及 AOI 等關聯。

這些是功能教具，不是標準電路符號全集、比例剖面、廠商 CAD、實際接線圖或帶電作業程序。箭頭表達功能關聯，未窮盡實物的所有功率、資料或機械路徑。每個工序保留自己的操作文字、判讀選項與證據要求；圖中的淡色高亮輪流提醒三個功能界面，**不宣稱是該道實體製造工序的位置**。原有專門編寫的操作題優先保留。

另外提供 25 個具有單位、輸入範圍、適用條件、局限與推理問題的互動算例，對應 93 門課。7 門沒有合適的此組算式，保持其課程與證據練習，不以不相干公式填滿。滑桿改變數值並畫出第一個變數的趨勢；位元数等離散變數的圖上取樣也保持整數。

| 算例 | 輸出 | 核心限制 |
| --- | --- | --- |
| 平衡三相實功率 | kW | 平衡、正弦、RMS 定義一致 |
| 變壓器峰值磁通密度 | T | 正弦磁通，不適用直接代入 PWM |
| 均勻導體 DC 電阻 | Ω | 一條固定溫度導體，不等於載流量 |
| 電容可用能量差 | kJ | 固定 C，另計 ESR 與轉換效率 |
| 正弦 PF 補償量 | kvar | 兩狀態滯後 PF，不涵蓋諧波共振 |
| 儲能續航 | h | 固定負載／效率，不是產品保證 |
| 庫倫計數時間尺度 | h | 不含充電末端電流變化 |
| 同步轉速 | r/min | 完整磁極數，不是極對數；感應機需滑差 |
| 表面 PMSM 轉矩 | N·m | 振幅不變 dq、峰值 iq、Ld=Lq |
| 軸功率 | kW | 同一軸上的轉矩與转速 |
| Buck 電感電流漣波 | A p-p | 理想 CCM，不適用 DCM |
| LC 自然頻率 | kHz | 集中理想元件，不等於完整 LLC 增益 |
| 開關損失粗估 | W | 三角形重疊，不含 Coss／恢復與導通損失 |
| 熱路徑溫差 | K | 指定兩節點的固定穩態熱阻 |
| RC 截止頻率 | kHz | 單極點、等效 R 定義明確 |

| 電阻熱雜訊 | µV RMS | 等效雜訊頻寬，不必等於 −3 dB 頻寬 |

| 量化 RMS | µV | 使用完整電壓跨度，不等於準確度 |
| Integer-N PLL 頻率 | MHz | 假設鎖定，不預測穩定性或雜訊 |
| VSWR 反射功率 | % | 共同實數阻抗參考面，不是輻射效率 |

| RC 收斂至半 LSB | µs | 滿刻度階躍、單指數，不含 slew rate |
| 壓電等效電容儲能 | µJ | 電場儲能，不是機械或聲學輸出 |
| PV 面積功率 | W DC | 固定條件，不是日發電量 |

所有預設是自行設定的教學案例；滑桿範圍不是設備額定、保護閾值、生產配方或現場操作值。公認數學關係以原創文字重新說明，沒有重製廠商插圖。適用的官方延伸資料連結列在算例下，完整課程來源另在「知識與來源」。
