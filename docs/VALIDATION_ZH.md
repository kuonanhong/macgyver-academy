## 已確認的修正

上傳的 V4 ZIP 與現有來源比對，除可攜副本移除站台身分外沒有使用者另行修改。截圖確認舊 CSS 開頭殘留字型 URL，導致 :root 變數未生效、部分按鈕白底白字；YouTube 畫面顯示錯誤 153。V5 完整移除無效 CSS 首行，播放器改用符合 Google 要求的真實 HTTP(S) 來源。

## 操作流程與語音

`tools/test-frontend.mjs` 驗證 4,000 次專案渲染、2,644 次中英工序渲染、連續三道真實課程步驟，以及組裝／觀察／製程／量測模式。全程講解、可略過按鍵導覽與獨立按鍵複習使用不同完成條件；僅複習按鍵不解鎖工序。輔助完成工具與設定後仍要求證據確認和獨立知識驗收。固定下一步按鈕顯示待完成條件；輔助可暫停、續播、完整復原。

既有實體方向鍵／WASD、中文輸入法與 Dead key、輸入欄位排除、複合鍵、放開後清理、失焦、雙手觸控、Shift 精调、復原、重設及姿態重載檢查通過。原進度遷移、帳號隔離、排隊儲存、409 衝突合併、筆記保存、語系偏好及非阻塞媒體亦保留。AI 教材上下文含相關技能，最大 5,573 字元，低於 18,000 字元上限。

`tools/test-mentor-guide.mjs` 有 12 組受控語音／DOM 測試：完整目標、步驟、觀察、異常、知識與驗收條件；每個控制的導覽目標；逐段文字模式；語音結束後才前進；非同步 voiceschanged；聲音缺失、逾時與錯誤；換頁／失焦／語言變更清理；同時只有一個講解；翻譯語系吻合與分批上限；知識展開、捲動及箭頭清理；目標避開固定操作列。未把知識測驗答案直接放進按鍵導覽。

1,322 個工序的原示範時間線、1322 任務控制的可達性與中英 SVG、六種工程算例、79 語系選擇／RTL／機器翻譯控制器的既有測試通過。專屬互動任務仍是 32 個，其餘 1,290 個為共用教學模型，102 種場景。

## 驗證界線

本環境沒有 Sites 支援的瀏覽器控制，未進行桌機／筆電／平板／手機實機視覺、觸控、聲音或 file:// 儲存政策的逐機驗收。Node VM 與受控 DOM 測試不能證明各瀏覽器呈現完全相同。手機建議使用 HTTPS 版，檔案預覽器未必執行完整 JavaScript。

尚未配置真實 AI 金鑰、下載模型權重或逐語言人工審校；生成式回答、77 種延伸翻譯與語音依配置及裝置能力而定。沒有替使用者執行自己的 GitHub／rclone 教材權重上傳。外部影片與 Google 地圖受登入、瀏覽器及服務限制；保留清楚的外開入口。

照片有來源與授權但跨工序重用；不是每步獨立實拍。工程圖是原創教學示意，不是廠商製造配方、核准施工程序或完整工業數位分身。
