## 電機與電子 100 門怎麼學

| 課程 ID | 子領域 |
|---|---|
| `a201`–`a210` | 發電與高壓設備 |
| `a211`–`a220` | 輸電、補償與保護 |
| `a221`–`a230` | 電網運轉與數位化 |
| `a231`–`a240` | 再生能源電力系統 |
| `a241`–`a250` | 儲能與供電整合 |
| `a251`–`a260` | 馬達與運動控制 |
| `a261`–`a270` | 功率轉換與電子 |
| `a271`–`a280` | 類比、射頻與訊號鏈 |
| `a281`–`a290` | 電路板、組裝與驗證 |
| `a291`–`a297` | 顯示、致動與工業介面 |
| `a298`–`a300` | 跨海直流輸電巨作 |

新課以四階段、24 步拆解，逐步提供目標、操作、觀察、失效判讀、驗收、知識點、測驗與公開引用。先了解系統目的與限制，再看師傅、操作教具、比較輸出與驗收條件。工程輔助可降低初學操作負擔，仍需理解數值與判讀理由。

兩門原有課程以追加方式升級：`a203` 大型電力變壓器由 12 步擴為 36 步；`a211` 高壓直流換流站由 24 步擴為 48 步。舊步驟的 ID、內容順序與已完成紀錄保留。課程增長後，原本的完成比例會重新按新版總步數計算，並不表示舊進度遭刪除。

電機／電子步驟採對應領域的概念圖、操作模式及部分計算教具；步驟數不等於每步都有獨立物理求解器。高電壓、旋轉機械、儲能及高能量設備的實際製造、施工與操作需專業場所和合格監督，網站不是原廠施工 SOP 或操作許可。

## 照片、架構圖與影片的實際來源

新增 31 個真實影像資產包括材料試樣、儀器、組裝、顯微影像及一張放射影像。每個素材保存作者、來源頁、授權連結、修改說明、代表範圍與雜湊；授權明細在 `public/academy/assets/photos/V10-LICENSES.txt`。不同教材可能引用同一張代表影像，它不代表特定廠商的量產線或該步驟的現場紀錄。不得移除原素材的姓名標示及個別 CC BY／CC BY-SA 等授權要求。

199 個既有半導體、封裝及矽光子主題另有原創中英學習圖與觀察任務，協助從模型、影像觀察、差異判斷走到驗收。這些 SVG 是教學關係圖，沒有冒充原廠截面、尺寸圖、保密配方或可製造 CAD。圖片內嵌文字只有繁體中文與英文兩版。

7 支新核對的官方 YouTube 影片按技術關聯使用，部分主題仍引用原有 ASML 背景影片。卡片下的中英重點及問題由官方影片說明與相關技術頁獨立整理；沒有下載、剪輯、轉載影片或複製字幕，也沒有宣稱逐部完整看完。標題／發布者／oEmbed 回應核對不等於所有地區可播放；使用原平台播放器與官方備援連結，不能繞過登入、年齡、地區或發布者限制。

頁面其他語言文字需要已設定的翻譯服務；原影片音軌、字幕由發布者提供。不能將機器翻譯的頁面摘要稱為該影片已有同語言配音。影像、官方閱讀與衍生工法的引用關係可在「知識與來源」依領域、子領域及課程查詢。

## 介面、聲音與個人偏好

頂部「我的工作室」提供淺色、深色、跟隨系統，以及舒適／緊湊版面。版面調整保留課程與功能。語音預設跟隨使用者選擇的頁面語言或瀏覽器語言偏好，不用 GPS、Google Maps 或 IP 猜測使用者母語；Google Maps 是工程據點參考。

可以單獨選擇講解語言、裝置具名聲音、語速和音高。瀏覽器並沒有統一可靠的男性／女性／專業程度欄位，所以介面提供實際聲音名稱與試聽；未安裝相符聲音則保留文字。翻譯準備完成才搭配其語系發音，缺少翻譯服務時不把未翻譯文章硬交給另一語言的聲音。部分裝置聲音會使用系統的網路語音服務。

繁體中文及英文為人工撰寫的核心教材；介面共有 79 個語言選項，另外 77 種需配置 AI 翻譯，沒有宣稱 79 種語言均已完整人工審校。偏好按目前帳號或本機檔案保存在此瀏覽器；設定匯出不含付款資料、登入憑證或課程進度。詳細說明見 [WORKSPACE_V10_ZH.md](WORKSPACE_V10_ZH.md)。

## 付費功能如何啟用

本次交付會員 UI 與可設定的伺服器金流，但 Sites owner/demo 及離線版的真實付款均未啟用，也沒有申請商家或刷卡。入門方案為 6 門免費試學、NT$299／30 天與 NT$2,490／365 天；後兩者是單次付款、不自動續扣的價格實驗，不能保證最佳轉換率。

GitHub Pages 只能提供靜態網站。Supabase 可以供個人帳號與進度同步，但公開課程 JSON 不會因加入登入按鈕就變成付費內容；完整 ZIP 更已包含教材。因此：

- 完整原始碼／離線包交給擁有者研究、備份與部署；若公開整包或發布完整 Pages，讀者可取得其中的教材。
- 實際收費需另部署 `COMMERCE_MODE=protected` 的 Python／SQLite 後端，單一 HTTPS 網域全部請求進入伺服器，不能由 Nginx、CDN 或其他公開路徑旁路送出教材。
- 填妥綠界商家與銀行資料、正式條款及私有金鑰後，學員只在綠界收銀台輸入卡號。本站驗簽並獨立查單後發期限權限，重送通知不重複加天。
- 免費試學及有效會員的每步答案在伺服器依序記錄；全課完成可申領帶驗證連結、可列印的本平台完成證書。它只記錄本平台開卷測驗完成，不是學位、工程師執照、真人監考或實體操作能力認證。沙盒證書標示測試，不能用來取得正式資格。

[COMMERCE_V10_ZH.md](COMMERCE_V10_ZH.md) 提供金流、結算、費用估算、退款對帳、設定與測試程序。Python 帳號與既有 Sites／Supabase 帳號不會自動合併；正式營運的信箱驗證、密碼重設、服務管理與客服仍須業主配置。

## 安全搬移既有進度

1. 在舊版「我的工程進度」匯出學習 JSON；研究工作表另用其匯出功能。若使用 Python 帳號，另外一致備份 `portable/data/` 的 SQLite 和私有教材索引。
2. 解壓 V10 到新的資料夾，先保留舊包。完整開啟 V10 最外層 `index.html`，核對側欄版號 10、電機與電子課程目錄。
3. 本機檔案模式受瀏覽器和資料夾路徑影響；必要時匯入舊學習 JSON，再核對幾門已完成的舊課。沒有把不同身分服務或不同課程版本自動合併。
4. 原 Python 服務先停止再做一致備份，使用同一資料庫路徑啟動新版；正式主機採備份 API 或停機複製，避免只複製正在寫入的 SQLite 主檔而漏掉 WAL。
5. 付費伺服器的新完成證書只承認伺服器的逐步測驗證據，匯入的離線完成旗標不直接發證。課程 hash 改變時，新版證書需完成新版證據，舊證書仍記載舊版本。

## 更新程式、公開教材、私人文件與模型

已附建好的離線檔，純學習不必建置。編修課程原稿時，從專案根目錄執行：

```bash
bash rebuild-curriculum.sh
bash build-offline.sh
```

首次或後續公開原始碼推送前，先在自己的 GitHub 建立倉庫並完成 Git 認證：

```bash
bash publish-github.sh --repo https://github.com/OWNER/REPO.git --dry-run
bash update-and-upload.sh --repo https://github.com/OWNER/REPO.git --rebuild-curriculum
```

這是會推送到你明確指定倉庫的指令範例，本次沒有代為執行。腳本使用隔離副本，保留原 Sites 倉庫 origin。**不要把完整公開匯出當成受保護付費教材的部署方式。** GitHub Pages 發布流程見 [GITHUB_UPLOAD_ZH.md](GITHUB_UPLOAD_ZH.md)。

私人文件及模型不進公開 Git；只有指定 rclone remote 才備份，使用 copy 而非刪除目的地的同步：

```bash
# 先用 rclone config 設好你自己的 privatecloud remote。
bash update-and-upload.sh \
  --repo https://github.com/OWNER/REPO.git \
  --documents /完整路徑/私人教材 \
  --index-documents \
  --documents-remote privatecloud:MacGyver/documents \
  --models-remote privatecloud:MacGyver/models
```

檢查目的地權限與素材再散布權。`.env`、會員／付款資料庫、API key、未完成下載與模型權重不納入公開 Git；權重也不自動放 Git LFS。這個備份不會訓練模型、上傳使用者信用卡或將私有教材加入公開課程目錄。

AI 路線保持瀏覽器 CPU 文字、Ollama 本機文字／視覺、llama.cpp CPU 及配置後的 Gemini；模型權重另行明確下載。沿用 [AI_ROUTES_V81_ZH.md](AI_ROUTES_V81_ZH.md)、[LOCAL_AI_V8_ZH.md](LOCAL_AI_V8_ZH.md) 與 [GITHUB_ACCOUNTS_V8_ZH.md](GITHUB_ACCOUNTS_V8_ZH.md)。Python 需 3.10+；`pip install python` 不會升級 Python 直譯器。
