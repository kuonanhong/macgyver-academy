# 交付內容與精度界線（V11 更新）

本版是可操作的工程教學平台與可追溯的公開知識。V11 有 2,066 項編輯選題、515 門逐步課程、13,042 步與 30,976 個知識點；其他 1,551 項為研究工作表。這些不是官方世界排名或已完成的工業 SOP。最新版內容見 UPGRADE_V11_ZH.md；以下保留歷代功能範圍並更新全站統計。

## 課程範圍

V11 聚焦資訊與資安 100 門、3,254 步及 80 門世界工程、960 步。原半導體 99 門、先進封裝／矽光子 100 門及電機／電子 100 門保留。

半導體製程與先進封裝深入課仍各 20 模組／520 步。每個新增步驟包含中英目標、操作、觀察、異常判讀、驗收、兩個知識點、測驗及來源。99 門是教學路徑的完整化，不代表已取得 99 套廠商量產製程；各 24 步課也沒有冒稱各有 500 道製程。

520 是拆解與分支的教學數量，不宣稱某晶圓廠固定使用 520 道工序。順序是學習導航，前置關係不是量產派工；公開原理不等於實際設備 recipe、潔淨室作業資格、專利許可或核准施工文件。學習任務會要求比較／判讀資料，但不是每步都內附真實晶圓量測檔。

研究工作表提供範圍、來源、介面、取捨、工序、量測、風險及審查八類任務，需要文字證據才能標記。它們不計入 13,042 道已編寫教學步驟，也不視為完整製造課程。部分歷史技術前身早於近百年，並非只選最近百年工程。

## 真實素材、圖示與引用

本版增加半導體真實照片、原創主題架構圖及官方影音入口。照片／顯微圖核對發布來源與授權，並標示作者、來源、使用範圍及必要的改作說明；數量以 `public/academy/data/release.json` 為準。

代表照片可在多門課或多步驟使用；沒有把同一照片重複計作多張新實拍，也不聲稱每步有獨立工廠照片。設備外觀或晶圓照片不能證明內部奈米結構、特定缺陷、製程公差或專有配方。99 項半導體專題的原創主題圖示與架構圖是概念視覺，不是製造 CAD 或廠商背書。

「官方資料與延伸閱讀」「照片與授權」可依工程分類、半導體子領域、引用課程與關鍵字篩選。引用索引依實際資料欄位建立，區分課程／階段／步驟／知識點；同一分類不會自動產生引用。分類是本站教學整理，不冒稱原作者使用相同分類。

影片由官方頁或原播放器提供，點擊後才連線；沒有在 ZIP 重新散布影片，亦未宣稱每部影片都已完整觀看或逐字轉錄。公開 HTTPS 播放器可避免學院／ChatGPT 登入外殼阻擋，但不能繞過 YouTube、發布者、地區、年齡、Cookie 或網路要求；失敗時提供原站入口。

## 師傅示範、雙手操作與工程輔助

每步提供教學目標、操作、觀察及驗收說明，搭配可略過的按鍵教學、紅箭頭、文字與裝置語音。師傅示範與學徒狀態分開；工程輔助可帶入教學操作並標示輔助，觀看示範不直接算完成。

工作台附鍵盤與觸控、左右手方向控制、旋轉、升降、抓取／釋放、精調、吸附、撤銷與重置。學員需完成任務證據及驗收才前進。輸入欄位與對話框保留正常打字，不搶用方向鍵。

部分步驟有專屬互動題，其他步驟依主題共用概念場景；準確覆蓋見 `docs/EXERCISE_COVERAGE_V11.json`。圖中的定量題是明示的教學樣本，不是廠商數據。示範不是 13,042 個獨立工業數位分身，也不是有限元素分析、機台控制或實際製程求解。

## 進度與帳號

直接 HTML 及未配置雲端服務的靜態網站提供本機學習檔案，姓名與信箱只作辨識。它不驗證信箱、沒有安全登入，也不跨裝置同步；共用電腦上不能視為保密。儲存被瀏覽器拒絕或額度不足時有暫存／備份提示，應匯出 JSON。

GitHub Pages 的可選雲端帳號由站長自己的 Supabase 提供，含信箱密碼驗證、註冊驗證信、密碼重設、每名使用者 RLS 與版本衝突處理。網站只使用 publishable／anon key，不放 admin／service-role key。本版包含程式與 SQL，但**沒有配置真實 Supabase 憑證，沒有完成實際服務的跨裝置驗收**。

完成工序、概念組合與筆記可同步到同一已配置後端。細部操作位置／角度及獨立研究工作表以目前瀏覽器保存、JSON 搬移為主；不同後端的帳號不自動互通。登入身分切換及版本比對防止把舊請求的資料套給另一名使用者，雲端失敗仍保留裝置備份。

舊版 ID 不直接視為新版等價製程；V7 既有課程 ID 在 V8 保留。更新前應匯出進度、研究資料並備份 Python 的 `portable/data/`。

## 地理、歷史與相近工法

逐步課提供代表性據點、公開歷史／背景與相關專題。延伸比較說明相同原理、適用差異及練習，不聲稱兩工程採用相同商用設計。

Google Maps 點擊後載入；近似座標為明示的工程點、園區、城市或研究基地。多門半導體課可能使用同一機構代表點，不等於每門課都有不同工廠，也不代表整條供應鏈或唯一生產地。尚未查證的研究題目不臆造照片或專屬座標。定位需學員主動允許，不用 GPS 推測語言。

## 平台與多語

繁體中文與英文是隨套件提供的核心教材。共 79 個語言選項，另外 77 種依設定的 AI 進行機器翻譯，未完成人工逐語言審校；未配置服務時保留可用原文並顯示狀態，不假稱已翻譯。語音採裝置聲音，缺少對應聲音時以文字引導。

響應式 HTML/CSS 與預先封裝 JavaScript 可在當代桌面及行動瀏覽器使用，包含鍵盤與觸控控制。核心雙擊離線課程不需 Python 或 Node；手機／平板建議 HTTPS 網站，檔案預覽器未必執行本機網頁。Python 後端需 3.10+，開發 Sites 版需 Node.js 22.13+／pnpm。尚未逐作業系統、逐瀏覽器、逐款實機驗證。

## 生成式 AI 的能力與限制

師傅問答區分既有教材摘要、瀏覽器 CPU 生成及已配置伺服器生成。四個候選為兩個瀏覽器小模型（Qwen2.5 0.5B、Qwen3 0.6B）與兩個原生 CPU 選項（Qwen3 1.7B、4B）；依容量與相容性選擇，不宣稱普遍最佳或保證正確。

瀏覽器先取得明確下載同意，顯示容量、授權、進度與取消控制；固定官方 revision、大小與 SHA-256 通過才載入。隨附固定 wllama 3.8.1 及相容 WASM，權重不含在 ZIP。可卸載或清除專用快取；初始化取消可能需等待當前載入收尾。

CPU 推論設 `n_gpu_layers=0`；多執行緒需瀏覽器跨來源隔離，普通 GitHub Pages 使用單執行緒。`file://` 會在下載前提示改用 HTTPS 或本機 HTTP。低記憶體行動裝置可能無法載入模型，仍可學習課程。

原生 llama.cpp 腳本只綁定 loopback，以臨時 key 連接本機網站；Ollama 是另一選項，目前官方 macOS 要求為 14+，Intel x86 為 CPU。沒有把私人模型服務裸露上網，也沒有假定 GitHub Pages 能直接呼叫所有人的 localhost。

測試覆蓋下載同意、雜湊、取消、轉接契約、身份切換及同步衝突；**本次未下載大型權重執行真實推論，也未在您的 Intel Mac 比較模型速度**。生成內容仍可能出錯；來源與公式需核對。伺服器 AI 金鑰只應存在後端環境。

## 自有教材、權重與發布

本機管理者可匯入文字、Markdown、CSV、JSON、PPTX、DOCX 或有文字層的 PDF；PDF 需可選 pypdf，掃描件需 OCR。關鍵字索引不是訓練、微調或完整圖像理解；管理者教材是該服務共用，不是逐帳號私人文件庫。遠端 AI 會收到相關段落；本機模型則在本機處理。

`publish-github.sh` 將公開程式匯出到專案外的隔離副本，再提交／推送，不修改 Sites origin。`update-and-upload.sh` 先重建離線包與公開匯出預檢，可選重建教材索引；只在明確指定 rclone 目的地時備份私人教材／模型。未完成的模型暫存檔被排除，不默默以 Git LFS 上傳權重。

完整 ZIP 包含 HTML、程式、課程、照片、runtime、SQL、腳本與文件；不包含 `node_modules`、大型模型權重、私人帳號資料庫或外部影片。GitHub Pages 發布另需啟用 workflow；提供腳本不等於已替使用者推送、建立 Supabase 或公開網站。
