# 雙擊開啟工程學院

將 ZIP **完整解壓縮**到自己的資料夾，再雙擊最外層 `index.html`。這個入口直接開啟 `public/academy/index.html`，沒有 iframe，也不用安裝 Python、Node.js、Conda 或啟動 localhost。

離線套件包含全部公開課程 JSON、工作台程式、原創工序示意圖、已下載的授權照片與中英文介面。課程清單、操作、師傅示範、測验與進度記錄可直接使用。`data/` 新增的公開 JSON（包括媒體及相關研習）會隨重建完整嵌入，沒有把私人教材、AI 金鑰、帳號資料庫或模型權重嵌入網頁。

## 本機學習檔案

右上角可新增並切換有名稱的「本機學習檔案」。每份檔案有自己的專案進度、筆記及工作台操作記錄。這些檔案是這個瀏覽器的裝置儲存，**不是密碼保護的雲端帳號**，不會自動跨裝置同步。同一台電腦上能使用這個瀏覽器的人，也能切換這些檔案。

請在「我的工程進度」定期匯出 JSON 備份。換裝置或瀏覽器時，先建立／選擇要接收資料的本機檔案，再匯入備份。移動解壓縮資料夾、清除瀏覽器資料、使用無痕模式，可能造成原位置的儲存不可見或被刪除；先匯出再移動。

瀏覽器對 `file://` 儲存的政策不同。若儲存被禁用或空間用完，網站仍可在記憶體中操作，但會標示「僅本次開啟有效」。此時關閉頁面前務必匯出。手機的檔案預覽器不一定執行完整 JavaScript；若檔案預覽無法操作，請用支援本機 HTML 的瀏覽器，或使用已部署網站。跨平台的已部署版本不受本機檔案預覽限制。

## 需要網路的部分

外部官方來源、影片與 Google 地圖仍需要網路。點開這些外部資源才會載入；離線課程不會把網路失敗誤當成未完成工序。

直接開檔模式沒有生成式 AI 服務；顯示的是清楚標記的既有教材說明。要用真正的生成式師傅問答，可依 `docs/BACKEND_ZH.md` 設定伺服器環境，再執行 `run-local.sh`／`run-local.bat`；本機密碼帳號與離線學習檔案是不同儲存，請用匯出／匯入搬移進度。不要將 API 金鑰放進 HTML、前端 JS 或公開 JSON。

## 修改之後重建

維護者修改 `public/academy/` 的程式或 `data/*.json` 後，執行：

```bash
bash build-offline.sh
node tools/test-offline.mjs
```

重建需要 Node.js 18 或更新版，不需要 npm 安裝任何套件。建置器將專案目前使用的具名相對模組匯入打包成傳統腳本，保留各模組作用域；遇到不支援的模組語法或循環依賴會停止，不產出半成品。未來若要加入動態匯入、預設匯出或複雜第三方模組，需改用完整 ES module bundler。

產物包括 `app.bundle.js`、`offline-data.js`、`offline-build.json`。`bootstrap.js` 在直接開檔時依序載入嵌入資料、本機儲存橋接器及程式；在 HTTPS/HTTP 上只載入程式，仍使用原本後端身分、進度和 AI API。

`update-and-upload.sh`、`push-updates.sh`、`deploy-static.sh` 都會檢查來源與產物 SHA-256。發現變更時先重建，再進行既有操作；產物已最新時可直接使用預建版本，不要求安裝 Node.js。純粹雙擊使用網站永遠不需要執行建置指令。
