# V6 驗證紀錄

## 資料與既有進度

- 2,000 個唯一題目 ID；37 門逐步課程、1,963 個研究題。
- 1,562 道學習工序、3,124 個知識點；新增 20 門各 3 階段／12 步。
- 399 筆來源索引、49 張附授權照片、31 個影片資源（30 個提供頁內播放器入口）、37 個地點。
- 原 V5 的 17 門完整階段／工序資料與新版本逐一比對一致；既有完成 ID 不更換。
- 課程前置 ID、來源 ID、雙語欄位、測驗答案、圖片存在性及授權資料通過資料驗證。
- 科技與移動系統課程經另一位協作作者檢查算式與測驗；修正油電功率邊界假設及聲學雙程路徑解釋。

## 互動與離線

前端回歸涵蓋 4,000 次雙語專案頁呈現、3,124 次雙語步驟呈現、全部 37 門實際開始課程處理流程、2,000 列 CSV、20 領域統計與 37 個地圖入口。

既有鍵盤、IME／實體按鍵碼、焦點、長按、雙手操作、工程輔助、師傅示範、語音文字流程、下一步、連續三步通關、筆記、帳號隔離及衝突合併回歸保留。跨課程會清除上一課的階段篩選。

研究工作表驗證八道雙語關卡、證據先於勾選、學員／專案隔離、有界 JSON 匯入、合併既有證據、拒絕異專案資料、HTML 逸出及儲存失敗提示。「我的專案」另列本装置研究工作表，不充作雲端同步或導學課程完成率。

直接開啟的傳統 JavaScript 封裝，在禁止任何原生網路請求的 Node VM 中啟動真實首頁與工作台，驗證完整 9 組嵌入資料、3 個本機學員、重新載入、備份還原、儲存拒絕備援與後端模式不被攔截。這是程式層驗證，不取代各瀏覽器對 file:// 的實機政策檢查。

## 影片

獨立播放器已由 Sites 設為 public；其發布包僅 5 個靜態檔案，沒有帳號 API、學習紀錄、資料庫綁定或 AI／地圖金鑰。24 個 YouTube ID 來自已選定的課程影片；其餘影片採已有的官方播放器或串流入口。

匿名 HTTP 請求（未附 Cookie／Authorization）確認播放頁與設定檔回傳 200，沒有 ChatGPT 登入轉址，且包含新增 PUB 影片。部分自動請求使用預設 Python User-Agent 時被網路／網站拒絕；相同匿名檢查識別標頭下成功。不宣稱完成各部 YouTube 影音解碼或使用者瀏覽器中的播放測試。

媒體回歸驗證點擊後才載入、file／HTTPS 分流、真實來源參數、跨視窗來源／nonce／影片 ID 驗證、拒絕非教材影片、錯誤 153 提示、直接開啟連結及事件清理。新增四部影片透過發布者官方頁／YouTube 公開 oEmbed 核對頻道與識別碼，未下載或重新發布影片檔案。

## 驗證界線

這個環境沒有可用的受支援瀏覽器 QA 工具，未安裝瀏覽器或另啟替代預覽流程。HTML／CSS、互動處理、來源資料及離線封裝經程式檢查；尚未逐款驗證 Windows／macOS／Linux／iOS／Android 的實機顯示、觸控、語音及所有外部影片。任何課程、模型或測驗完成均不代表取得製造、施工、操作或認證資格。
