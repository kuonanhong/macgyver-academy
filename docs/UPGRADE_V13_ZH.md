## 1. 橋樑與建築 100 門逐步課程

- 目錄「橋樑與建築」的 100 個主題全部改為逐步課程；96 門新課每門 **5 階段 × 8 步 = 40 步**，比 V12 光學（32 步）更深。
- 5 個階段：①工程背景、荷載與結構系統 ②材料、構件與接合細部 ③施工方法與施工階段控制 ④試驗、量測與監測驗證 ⑤耐久、維護與工程交接。
- 每門有 10 個技術單元，每單元拆成 4 步：**傳力機制 → 定量算例 → 試驗驗證 → 失效診斷**；每步有目標、操作任務、觀察（含「現場實務」）、失效判讀、驗收、中英知識點、測驗與公開來源。
- `danjiang`（淡江大橋）18→58 步、`b003`（明石海峽大橋）12→52 步、`b015`（舊金山金門大橋）24→64 步、`b021`（台北 101）24→64 步：舊步驟 ID 與順序完全保留，新步驟接在後面。
- 每門另附 **工程檔案**：6–10 項關鍵數據、3–6 個年代里程碑、2–4 項相關規範與標準、2–4 個代表工程比較；另有「傳力、算例與驗證」補充指南、兩門相關課程比較、地圖地點與歷史時間軸、相關公司與股價。
- 12 個子領域：懸索橋與主纜、斜張橋與斜索、拱橋／高架橋／跨海通道、橋梁施工工法與大型架設、支承／伸縮縫與橋梁耐震、橋梁耐久與健康監測、超高層建築巨作、高層結構系統與減振、地標建築與大跨度屋蓋、混凝土與鋼構施工、建築耐震／預鑄與防火、帷幕牆／垂直運輸與數位營建。課程地圖新增「橋樑與建築」主線與兩條學習路線。
- 每門課有原創架構圖（23 種結構圖示，如懸索、斜張、拱、高架、節塊、支承、外伸臂、阻尼器、膜屋蓋、薄殼、帷幕牆、測量），工作台的新步驟使用「架構與證據的工程判讀」互動任務。
- 課程索引：`public/academy/data/bridges-buildings-100.csv`；原稿與產生程式：`tools/structures-v13/`、`tools/integrate-structures-v13.py`。
- 這些是依公開原理、官方資料與規範架構編寫的原創教學，不是設計圖說、施工計畫或吊裝／張拉作業許可。

## 2. 收費：每門只有第一節免費，價格依語系換算當地幣別（參考華佗學院做法）

- 方案不變：**30 天 NT$299、365 天 NT$2,490**（`public/academy/data/pricing.json`）。
- 免費範圍：每門逐步課程的第一節（第一個階段）；**沒有任何整門免費的課程**。V13 一併修正代管版 `app/api/billing/config/route.ts` 與條款頁中殘留的「6 門免費」設定。
- 幣別依觀看者的**語系**推定（例：介面選日本語 → 日圓；繁中台灣 → 新台幣）；語言對應多國時（英文、西文…）再依時區與瀏覽器語言地區判斷；學員可手動切換。不使用 GPS 或 IP。
- 匯率依序取用：①本站 Supabase `fx_rates`（與伺服器收費同一份，每 12 小時更新）②瀏覽器向 open.er-api.com 取得的最新匯率（快取 12 小時，與華佗學院相同）③套件內每週快照。
- 換算後**無條件進位到當地慣用價位**（與華佗學院相同規則）：例 USD 9.49、EUR 8.99、JPY 1,400、KRW 12,500；永遠不低於「台幣價 × 匯率」。網頁 `tidyPrice()` 與伺服器 `amountFor()` 規則相同並有自動測試逐幣別比對。
- 刷卡：PayPal（含「Debit or Credit Card」）與綠界信用卡（3-D 驗證）的官方頁面；伺服器向金流商核對金額、幣別、訂單後才開通。撥款到你的郵局帳戶只在金流商後台設定，帳號只寫在 `owner-private/`（不上傳、不出現在任何網頁或程式）。設定步驟：`docs/PAYMENTS_V12_ZH.md`。

## 3. 模型與私人倉庫

- 網站學徒問答需要的權重：`Qwen2.5-0.5B-Instruct Q4_K_M`（約 491 MB，預設）＋`Qwen3-0.6B Q8_0`（約 639 MB，與華佗學院同一檔案）。原生 CPU 可選 `Qwen3-1.7B Q8_0`（約 1.83 GB）。
- `bash macgyver.sh models`：已存在就驗證；Qwen3-0.6B 會先從華佗學院四份 ZIP 或已還原的 GGUF 匯入；其餘從官方固定版本下載並核對 SHA-256。
- 上傳到 `kuonanhong/PRIVATE-MODELS` 的 `projects/macgyver/`：40 MiB 內容定址分片，只傳雲端沒有的；與華佗已上傳的相同內容直接引用、不再傳送；只增刪自己的資料夾。比對：`bash macgyver.sh models-compare`。
- 網站讀取私人倉庫的方式：Cloudflare Worker 代理（token 只在伺服器端），`config.js` 填 `modelMirrors`；未設定時從 Hugging Face 官方下載。詳見 `docs/AI_MODELS_V12_ZH.md`。

## 4. 一鍵比對與上傳

```bash
bash macgyver.sh doctor            # 第一次：檢查 git、Python、SSH、兩個倉庫
bash macgyver.sh compare           # 網站：新增 / 修改 / 刪除 / 相同
bash macgyver.sh models-compare    # 模型：已存在 / 可引用 / 需上傳 / 將刪除
bash upload-all.sh                 # 一鍵：網站只傳差異並刪除多餘檔案，再上傳新權重分片
```

V13 刪除了多餘的 `upload-github-ssh.sh` 與 `docs/GITHUB_SSH_UPLOAD_ZH.md`；`compare` 會把它們列為雲端「刪除」。
