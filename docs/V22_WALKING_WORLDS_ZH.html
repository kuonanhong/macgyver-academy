第一次進入

V22 的主要入口是 public/academy/experience.html。每條故事的六個製程站放在同一個可行走空間；人物可以沿走道自由移動，切換鏡頭，靠近設備後開啟任務。工程領域與故事目錄仍可用卡片搜尋，進入後則使用連續場景。

  1. 先啟動本機網站，或開啟已部署的學院網站，再選「全畫面工程世界」。
  2. 選擇一個領域與故事。初次進入時，先看「目前目標」中的第一站任務。
  3. 按「帶我前往」或鍵盤 G，觀察人物沿可通行走道到達設備旁。也可自行使用鍵盤或搖桿行走。
  4. 接近設備後，按 E 或畫面「互動」按鈕。閱讀證據、做出選擇並儲存筆記，完成本站後再走往下一站。
本機必須透過 HTTP 開啟。新版行走程式使用 ES 模組。解壓後請執行 run-local.sh 或 run-local.bat；直接雙擊 HTML 的 file:// 開啟方式不會啟動新版 3D 行走。

怎麼完成一條工程旅程

  1. 辨認設備與目前目標。小地圖標出站位與人物位置；「目前目標」顯示要前往的章節。可先用跟隨視角認識走道，再切第一人稱觀察。
  2. 走到工作站。自行行走、點地面，或按「帶我前往」。抵達後，設備旁會出現互動提示。
  3. 選擇角色。任務面板提供該故事原有的三種專業角色。不同角色會改變任務切入角度、結果說明與獨立進度。
  4. 閱讀觀察證據。逐項展開證據。可開啟「真實影像」，確認照片的拍攝範圍、作者、來源與授權；需要時再切到原有定點全景模式。
  5. 留下工程判斷。證據閱讀完成後選擇方案，查看對應角色的後果說明；學習筆記可記錄量測條件、未知假設、版本與待查問題。
  6. 完成本站並前進。按「完成・下一步」記錄結果，任務面板關閉，人物留在當前位置。下一站成為目前目標，再沿走道繼續。

「帶我前往」記錄為輔助行走；它負責帶路，不會代替閱讀證據或做工程決策。完成六站代表完成這條模擬故事，原有逐步課程的學習與通過條件仍各自保存。

角色、進度與學習筆記

V22 使用獨立的行走故事紀錄，保存已讀證據、工程選擇、完成章節、學習筆記、人物位置及操作事件。不同角色有各自的故事進度；切換角色會回到該角色的紀錄。

行走進度與原 V21 故事、逐步課程進度分開。既有課程與 V21 紀錄仍保留；完成行走任務不會直接替原課程打勾。紀錄依本機使用者或已登入帳號分開識別，瀏覽器的本地儲存仍是本版行走紀錄的保存位置，不能把登入視為已自動跨裝置同步。

  1. 在任務面板輸入學習筆記，按「儲存筆記」。切換任務或關閉面板時也會保留目前筆記。
  2. 按右上角「?」開啟操作說明，再選「匯出紀錄」，取得目前故事的 V22 JSON。
  3. 換裝置後先進入相同故事，再使用「匯入紀錄」。匯入會檢查 V22 版本與故事識別碼；不同故事的紀錄不能直接混用。

無痕模式、清除網站資料或瀏覽器禁止本地儲存時，紀錄可能無法長期保存；需要保留學習歷程時，可使用匯出功能。

下載、啟動與一鍵上傳

1．下載並解壓

完整 ZIP 與四個替代 ZIP 擇一。若用替代包，四包都要下載；它們共同組成完整專案。將 ZIP 與 Install_and_Upload_MacGyver_v22.sh 放在同一資料夾並保留檔名。以 macOS 的「下載」資料夾為例：

cd "$HOME/Downloads"
bash Install_and_Upload_MacGyver_v22.sh --extract-only

腳本會檢查本次發行的壓縮檔及檔案清單，再解壓為 MacGyver_Engineering_Academy_v22。--extract-only 只處理安裝，不連線上傳。重跑時保留本機修改與新增檔；遇到新版檔案與本機修改衝突，更新檔放在 .macgyver-updates-v22 供合併。

2．啟動網站

bash "$HOME/Downloads/MacGyver_Engineering_Academy_v22/run-local.sh"

Windows 可執行專案中的 run-local.bat。需要 Python 3.10 以上版本。啟動後依終端機顯示網址開啟學院，選「全畫面工程世界」。預設連接埠通常是 8010；若已被使用，啟動工具可能另選連接埠，請以實際輸出為準。

若只測試已建置的靜態前端，也可在專案根目錄執行下列命令；它只提供靜態檔案，不包含會員驗證及 AI 後端：

python3 -m http.server 8080 --directory public/academy

然後開啟 http://127.0.0.1:8080/experience.html。

3．一鍵增量上傳

本機需已有 Git、GitHub SSH 金鑰及對目標倉庫的權限。安裝後執行：

cd "$HOME/Downloads"
bash Install_and_Upload_MacGyver_v22.sh

這會沿用既有的公開網站匯出與增量上傳流程。若要一併處理現有模型／權重和私人文件：

bash Install_and_Upload_MacGyver_v22.sh --with-assets

公開網站更新送到 kuonanhong/macgyver-academy；模型與私人文件沿用獨立的私人資產同步流程，目的地是既有 kuonanhong/PRIVATE-MODELS。腳本使用現有檔案，依既有同步機制分批、校驗與重試；不會因執行上傳而自動下載大型模型。

也可明確指定目前模型與文件資料夾：

bash Install_and_Upload_MacGyver_v22.sh --with-assets \
  --models-dir "/完整路徑/我的模型" \
  --documents-dir "/完整路徑/我的文件"

只想先查看差異，可加 --dry-run；它可能安裝並連線比較，但不提交或推送。Windows 的 Bash 上傳流程可在 Git Bash 或 WSL 使用；平常瀏覽網站的手機與平板不需要安裝 Bash 或 Python。

讓 AI 師傅回答目前任務

右上角或任務面板的「AI 師傅」沿用既有模型連接介面，會帶入目前工程故事、章節、角色任務、觀察證據與來源。可問「這一步要先量哪個量？」、「這張照片能支持哪些判斷？」或「如果換另一個假設，需要什麼對照？」。

生成式回答需要可用的本地模型或已配置的後端 API。套件提供接線程式與相關工具，不附大型權重及供應商 API 金鑰；靜態 GitHub Pages 本身不會執行模型推論。請依專案原有 AI 設定說明啟動本地服務或部署後端，並在 AI 面板選擇可用路線。

模型／權重同步只是保存或傳輸檔案；還需要模型執行環境載入權重，AI 才能產生回答。服務尚未設定時，仍可進行行走、閱讀教材與保存故事紀錄。

常見問題

為什麼雙擊 HTML 只有啟動說明？

這是本機檔案入口。請先執行 run-local.sh 或 run-local.bat，再用瀏覽器開啟啟動網址；新版 ES 模組需要 HTTP。原有照片／定點全景模式另有保留入口。

為什麼人物走近之前不能完成任務？

互動依設備距離啟用。先靠近設備，或按「帶我前往」，再使用互動鍵。若完成按鈕仍未啟用，請閱讀每項觀察證據，並做出該站需要的工程選擇。

為什麼顯示可行走平面場景？

裝置或瀏覽器無法建立 WebGL 時，會使用連續可行走的 2D 備援。它保留人物、工作站、距離互動與任務，視角選項會依可用能力調整。

手機畫面太擠時怎麼辦？

收合目前目標面板，先使用搖桿行走，走近後再展開任務。橫向使用能增加觀察空間；原生全螢幕是否可用依裝置與瀏覽器而定。

這次是否增加了 1,740 個新課程？

1,740 是既有 290 條故事的章節總數。本次把它們接到連續行走的設備站，改善空間、鏡頭和互動；原有逐步課程內容與識別碼另行保留。

為什麼選了語言還有英文？

20 個語言內建主要操作字典；完整教材的其他語言仍需翻譯服務。尚未翻譯的內容會保留可閱讀原文，避免把語言選單當成已完成翻譯的證明。
