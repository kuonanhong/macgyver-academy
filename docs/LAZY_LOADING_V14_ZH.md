# V14 首頁優先與按需載入

首頁 HTML 先顯示工程學院介紹與入口；程式只需讀取精簡目錄即可顯示搜尋、分類與課程地圖。完整課文、媒體、延伸技能、地點故事、廠商與課程引用在開啟該課程時才載入。

- `data/lazy/index.json` 與 `offline-data.js`：精簡目錄、課程順序、照片資訊及單課檔案索引。目錄保留所有步驟 ID，所以未下載的課程仍能正確計算既有進度。
- `data/lazy/courses/`：每門逐步課程或研究題目的完整資料。
- `data/lazy/resources/`：每門課程的媒體、比較、地點、廠商及來源。
- `data/lazy/data/`：來源庫、精確引用反查、完整工程地圖等按頁載入資料。
- 課程順序維持原始 `featured.json` 順序；總目錄順序維持 `catalog.json`。

HTTP 使用相對網址，支援 GitHub Pages 子目錄。單課檔案名稱含內容雜湊，並驗證位元組數與 SHA-256；一般 HTTP 沒有 Web Crypto 時仍使用本機 SHA-256 計算。重複請求合併，失敗可重試。導頁與帳號代次檢查防止遲到的回覆覆蓋新頁面或新帳號。

直接開啟完整解壓縮後的根目錄 `index.html` 時，改用按需傳統 JavaScript 檔；不依賴 `fetch(file://)` 或 ES module。手機與平板宜使用已部署的 HTTPS 網址；ZIP 預覽器不是完整瀏覽器。瀏覽器不提供持久儲存時，介面會明確標示僅存於當次使用。

首頁不等待帳號服務、全部媒體或行情。敏感頁面則先等待帳號準備完成，再讀取可見的課程內容。課文載入失敗有重試按鈕。註冊等待信箱驗證時保留驗證對話框，背景頁面會恢復目前路由。

## 付費內容

分檔本身不提供付費保護。公開保護版必須先剝除付費階段，再重建全部 lazy 與 offline 檔案。伺服器保護模式的目錄與單課內容分別使用 `/api/curriculum?index=1`、`/api/curriculum?courseId=...`，不從完整擁有者靜態快取回退。

帳號切換會同步還原已填入的付費階段為公開 stub，清除權限與私有內容快取。遲到的權限或課文回覆不會授權另一帳號。完整擁有者離線套件仍是可查閱完整課文的版本。

## 重建與驗證

```bash
bash build-offline.sh
python3 tools/check-offline.py
node tools/test-lazy-v14.mjs
node tools/test-lazy-access-v14.mjs
node tools/test-offline.mjs
node tools/test-account-race-v10.mjs
node tools/test-curriculum-loader.mjs
```

`data/featured.json` 是完整教材原始資料；`data/course-parts/` 保留給原始教材還原與既有建置工具。首頁不再逐一下載這些整套課程分段。所有生成檔雜湊寫入 `offline-build.json`。

2026-10-21 最終 V14 測量：2,066 個專案、807 門逐步課程、24,274 步。首頁離線目錄 `offline-data.js` 為 4,213,068 bytes；完整課文 `data/featured.json` 為 130,092,461 bytes。建置包含 51 個程式依賴模組、18 個原始教材還原分段，首頁不預載這些分段。這是未壓縮資料大小，不是網頁載入秒數，也不包含程式、樣式與圖片。

驗證涵蓋所有單課資料保留、引用反查一致性、重複載入、重試、SHA-256、私有回覆不共用快取、離線完整首頁／工作台、本機進度保存、帳號與導頁競態。前端測試使用 Node VM 模擬 DOM，不能代表實體 iPhone、Android 或桌面瀏覽器的排版與效能測量。最終完整雙語逐步渲染測試已通過，結果另存 `FRONTEND_VALIDATION_V14.json`。

### AI 問答入口的課文權限

已補上工坊全域 AI 問答入口的檢查：只有完成載入而且目前步驟可讀，才提供該步詳細課文與操作狀態。未載入、被鎖或通行證失效的步驟僅提供公開專案摘要。實際 `currentTutorContext` 的三個針對斷言通過，避免保留在記憶體的舊課文經由問答入口繞過頁面鎖定。

背景帳號檢查現在保留首頁與目錄的公開畫面，避免已出現的首頁被網路等待畫面蓋住。工坊、專案及學習地圖仍會立即清除舊帳號內容。延遲課程權限回應下的首頁與目錄可見性已由實際 `initAccount` 函式測試通過。
