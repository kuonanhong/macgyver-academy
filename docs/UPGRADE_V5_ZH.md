# V5 操作與更新指南

本版維持直接開啟 HTML 的方式，改善「第一次不知道怎麼操作」的流程。`馬蓋先` 的英文名稱為 **MacGyver**。更新前請在舊版「我的工程進度」匯出 JSON；完整解壓新套件後雙擊最外層 `index.html`，必要時匯入 JSON。不要只複製一個 HTML，也不要直接在 ZIP 預覽器內操作。

## 一次練習的順序

1. 在逐步課程進入工程工作台，先按「開始師傅講解」。瀏覽器通常需要這次點擊才允許語音。
2. 師傅先說明目標、程序、觀察與判斷，再依動作示範。紅箭頭指出正在解說的元件或控制鍵；可以略過按鍵教學、暫停、繼續或重播。
3. 看完示範後，手動操作左側工作台；第一次可用學徒桌檯上方的「工程輔助」。輔助完成的操作會標記為輔助練習，仍須確認操作證據並回答知識驗收。
4. 使用明顯的「下一步」入口；尚未完成時，它會引導至欠缺的示範、操作證據或驗收，不會悄悄跳過學習條件。
5. 使用頁面上方的相關技能入口，查看可轉用原理、差異、三步比較練習及資料來源。工程地圖、歷史與故事列於專案頁，也可從工作台查閱。

| 操作 | 鍵盤 | 觸控／滑鼠 |
|---|---|---|
| 抓取／放開工具 | Space | 抓取／放開按鈕 |
| 左手平面移動 | 方向鍵 ↑ ↓ ← → 或 W A S D | 左手方向板 |
| 升降 Z | I / K 或 PageUp / PageDown | 右手升降鍵 |
| 旋轉 | J / L 或 Q / E | 右手旋轉鍵 |
| 精細移動 | 按住 Shift | 精細移動鍵 |
| 復原 | Ctrl+Z／介面復原鍵 | 復原鍵 |
| 暫停操作 | Esc | 暫停／停止引導 |

工作台使用實際鍵碼，支援中文輸入法開啟時的方向控制。在筆記、聊天或其他輸入欄位打字時不攔截方向鍵；先點工作台或「啟用鍵盤」。尚在示範時會提示原因。製程、量測、觀察步驟還有各自的設定、判斷及記錄按鈕，不是只把圖形移到指定位置。

## YouTube 錯誤 153

Google 要求嵌入播放器提供 HTTP Referer 或等效來源識別。直接由 `file://` 開啟 HTML 無法自行捏造這個 HTTP 標頭；加一個假的 origin 參數也不能正確解決。

V5 在 HTTPS 網站使用具正確來源政策的播放器；本機 HTML 經設定的 HTTPS 播放器頁面載入影片，讓 YouTube 接收到真正的網頁來源。完整課程與控制仍在本機 HTML 執行，影片本身需要網路。若線上播放器需要登入、瀏覽器封鎖第三方 Cookie、影片發布者禁用嵌入或服務不通，頁面提供清楚的狀態、開啟線上播放器及原站連結。權限不會自動改成公開，也不會下載／重製 YouTube 影片。

預設線上播放器位於目前學院網站。部署到您自己的 HTTPS 網站後，可設定自己的播放器 URL；具體設定與錯誤處理見`docs/VIDEO_PLAYBACK_V5_ZH.md` 及 `public/academy/` 播放器程式。公開網址只包含影片識別碼及播放設定，不含帳號或學習筆記。

## 語系與語音

介面依瀏覽器語言偏好選擇，不以 GPS 猜測語言。繁體中文、英文是已附的完整核心教材。其他 77 種語言需要已設定的 AI 翻譯服務；翻譯成功後才使用對應文字，不把英文改成日語語音就宣稱已翻譯。

朗讀使用作業系統／瀏覽器提供的語音，並非包內附 79 套語音模型。可用語音依裝置而異；沒有相符語音、被瀏覽器阻擋或沒有翻譯服務時，介面會說明並保留文字與逐段操作。部分系統語音會連線語音供應者。地圖語言也跟隨所選語系；不需為了語系取得學員的 GPS。

## Google 地圖、歷史與相近技能

17 門逐步課程各有代表性據點、原創中英歷史故事、學習連結與公開來源。地點是工程案例／代表性研究或製造據點，不代表整條供應鏈只在一處。地圖須主動點擊後才向 Google 連線，另附原站連結。預設使用地圖嵌入頁；需要正式 Maps Embed API 時，可在公開設定 `window.MG_CONFIG.googleMapsEmbedKey` 提供已限制網站來源的瀏覽器金鑰，並啟用 Google Maps Embed API。不要把伺服器秘密金鑰放入前端。

17 門課程已有 115 組經編寫的相關技能比較；其餘 1,983 個題目提供明確標示的同領域研究入口，沒有冒稱每題都已完成專屬教案。

## 程式、教材、模型的更新上傳

可直接使用的 HTML 不需要 Python。只有可選後端、教材索引與管理腳本才使用 Python 3.10+；Python 要由系統安裝器安裝，不能用 `pip install python` 升級直譯器。`pip` 是安裝 Python 套件用的。

先安裝 Git 並完成自己的倉庫認證。如需遠端備份教材／模型，先安裝 rclone、完成 `rclone config`。以下把目的倉庫、實際資料夾與 remote 名稱換成您自己的值：

```bash
bash update-and-upload.sh \
  --repo https://github.com/kuonanhong/YOUR_REPOSITORY.git \
  --index-documents \
  --documents /完整路徑/教材資料夾 \
  --documents-remote myremote:macgyver-documents \
  --models-remote myremote:macgyver-models \
  --message "Update MacGyver lessons and models"
```

腳本先檢查教材路徑、重建有變更的離線程式，再索引教材、以 `rclone copy` 備份、提交與上傳程式。`copy` 不刪除遠端額外檔案；Git 不強推。私有教材請放專案外或 `local-documents/`，模型放 `models/`；不把帳號資料庫、私有教材索引和 API 金鑰放進公開網站。

macOS／Linux 可直接執行 Bash；Windows 使用 Git Bash 或 WSL 執行 `.sh`，亦附本機服務與 AI 的 `.bat`／PowerShell 入口。只看教材的手機、平板不執行 Bash；使用 HTTPS 網站即可。

改動公開資料與原始碼後執行 `bash build-offline.sh`；重編需要 Node.js 18+，使用預建套件不需要 Node。重新產生所有課程資料使用 `bash rebuild-curriculum.sh`。純靜態發布使用 `bash deploy-static.sh`。

## 生成式 AI 與內容範圍

`bash run-ai-local.sh` 可啟動 Ollama／本機後端；`index-documents.sh` 建立教材索引。模型權重由您按模型授權另行下載，套件不附大型權重。已設定 API 的伺服器可提供生成式回答、機器翻譯及帳號進度；直接開啟 HTML 則提供課程知識回覆與瀏覽器本機學員檔案，沒有跨裝置帳號同步。

目前包含 2,000 題研究目錄、17 門逐步課程、1,322 道教學步驟（半導體及先進封裝各 520）、2,644 個知識點。這些是教學拆解，不是廠商驗證過的製造配方。41 張真實照片作代表性引用，不是每步各有一張實作照片。32 項任務有專屬互動教學，其餘使用共用的可參數化教學模型；不是 1,322 套高擬真數位分身。外部影片、Google 地圖、所有裝置與所有語系仍受服務及瀏覽器能力限制。
