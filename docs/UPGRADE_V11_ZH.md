## 實作的方式與範圍

既有左右手工作台、鍵盤／觸控、師傅逐段示範、紅箭頭、工程輔助、驗收與下一步均保留。新課以對應架構與該步驟的原理判讀題呈現，學徒需要操作證據及測驗；不是每道步驟都有獨立物理求解器。

資訊算例包含管線、Roofline、仲裁、排程、可靠性、訊號與 AI 計算等；能源與資源模型包含熱力、風力、水力、地熱、PUE、礦石回收與流量。畫面標示參數、單位及假設；結果不是廠商效能或實測值。

雙量子位教具採理想 statevector，基底順序為 `|q0 q1⟩` 的 `00、01、10、11`。提供 H/X/Z/S/T/RY/CX/CZ/SWAP、Bell 範例、相位、機率、concurrence 及純度。它不連線 QPU、不含硬體雜訊，也不將退火機或拓樸候選當成通用閘硬體。

在課程內下載「12 個本機證據小實驗」，解壓後執行：

```bash
python3 run-evidence-labs.py --check > results.json
```

需要 Python 3.10+，不需 pip 套件、網路、GPU、模型權重或硬體。輸入是假想案例，實驗會核對獨立預期數值並保存來源雜湊。此套件不代表部署測試、工業 SOP 或實體技能認證；不會自動發證。

## 保留進度與更新

335 門非資訊 V10 課程以原始內容雜湊確認完全保留；另三門既有資訊課保留舊步驟並追加。完成比例按新版總步數計算。舊路徑仍有效，原研究題的 ID 保留；研究證據不自動當成新課測驗通過。

更新前匯出學習 JSON 和研究 JSON。解壓到新資料夾後，直接檔案模式的儲存可能隨瀏覽器／路徑改變；需要時匯入備份。Python 後端先一致備份 `portable/data/`；不把不同身分服務自動合併。

修改課程原稿與重建：

```bash
bash rebuild-curriculum.sh
bash build-offline.sh
```

重建腳本先恢復 V10 基準，依序整合 V8、V9、V10、V11，驗證引用與數量，再建立 9 個有雜湊的課程分段及完整離線檔。完整 ZIP 已含重建結果。

公開程式推送與明確指定的私人備份腳本仍附上：

```bash
bash publish-github.sh --repo https://github.com/OWNER/REPO.git --dry-run
bash update-and-upload.sh --repo https://github.com/OWNER/REPO.git --rebuild-curriculum
```

模型／私人文件另用明確 `--models-remote`、`--documents-remote`；帳號、密鑰、權重不進公開 Git。本次沒有代為推送您的 GitHub、下載權重、開通商家或更改網站公開範圍。
